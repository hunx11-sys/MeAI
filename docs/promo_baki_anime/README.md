# 영업지원도구 6종 — 바키 애니메이션풍 광고 (30초, 세로 1080×1920)

완성본 : `../meai_tools6_baki_anime_30s.mp4`

- 인물 그림은 **소유자가 준 캐릭터 콘티(2026-10-07)** 를 칸별로 잘라(글자 없는 부분만) 3배로 키워 쓴 것이다.
  붉은 머리(`red_*`) = 질문하는 선배 · 올백(`slick`) = 대답하는 동료 · 옆얼굴(`profile`) = 놀라는 동료 ·
  정장(`suit`)·장발(`long_*`) = 좌우 대결 · 뒷모습 무리(`group`) = 엔딩.
- 대사·장면 순서는 앞선 패러디판과 같다. 배수·건수는 **가정값**(화면에 표기).
- 타격감 : 타격 시점마다 화면 흔들림 · 흑백 반전 임팩트 컷(3프레임) · 흰 섬광 · 쾅 박히는 자막 · 필름 그레인.
- 배경음은 `music.py` 로 직접 합성(충격음·브람·점점 빨라지는 북).

다시 만들기 (이 폴더에서) : `python3 music.py music.wav` → `mkdir frames && python3 render.py "$(pwd)"` → ffmpeg 로 합치기(앞 README 참고)

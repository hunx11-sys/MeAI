# 운전자보험 「변호사 현물지원」 액션 광고 (18초, 가로 1920×1080)

완성본 : `../lawyer_driver_ad_18s.mp4` (취미 제작물)

| 장면 | 시간 | 내용 |
|---|---|---|
| 1 출발 준비 | 0~4초 | 폭발 · 붉은 연기 · 달려오는 정장 무리 앞, 파란 스포츠카에 조수석 여성과 손 잡고 탑승 → 엔진 공회전 → 튀어 나감. 제목 「변호사 현물지원담보 / 조기 판매종료 예상」 |
| 2 첫 벽 돌파 | 4~8초 | 증서 벽 「변호사를 직접 찾아야 하는 운전자보험」 → 가속 → 쾅! (느린 화면 0.6초, 종잇조각 흩날림) |
| 3 두 번째 벽 | 8~12초 | 「변호사를 서울에서만 보내주는 운전자보험」 → 더 빠르게 콰광! (화면 기울임 · 흔들림 더 크게) |
| 4 주차 + 따봉 | 12~18초 | 금빛 증서 「변호사를 전국 어디든 지원해주는 메리츠화재 운전자보험」 앞에 멈춰 서고, 운전자가 돌아보며 엄지 척 → 「삼성전자 말고 / 운전자 빨리 갈아타!」 |

- 운전자는 **실존 인물이 아닌 가상 인물**(각진 턱 · 올백 머리 · 왼쪽 눈썹 흉터 · 선글라스)이다. 참고 썸네일의 인물 얼굴은 쓰지 않았다.
- 그림 · 효과음 · 배경음은 모두 코드로 직접 그리고 합성했다(외부 그림 · 음원 없음).
- 벽 문구는 `ad.html` 의 `WALLS`, 소리 시각표는 `build.py` 의 `sound()` 에서 고친다.

다시 만들기 (저장소 루트에서)
```
python3 docs/promo_lawyer/build.py
```

## 7. 스마트 제안서 검수에서 드러난 담보·KCD 오류 반영 (ver2610 · 2026-09-18)

스마트 제안서 모듈(proposal_smart v8.8~v8.9)을 실제 설계 2건(54쪽·56쪽)으로 검수하는 과정에서, 제안서가 담보를 놓치거나 잘못 판정한 원인 상당수가 특약검색기 데이터에 있었다. 도구 6종 가운데 데이터를 갖고 있는 **특약검색기(tool.html)** 와 **통합치료비 시뮬레이터(통합치료비.html)** 에 아래를 반영했다. 나머지 4종은 이 두 파일의 데이터를 쓰지 않아 변경이 없다.

## 9. 「또 걸려도 또 받는 암보험」 2종 추가 (ver2612 · 2026-09-18)

`scripts/import_terms.py` 로 약관 PDF 2종에서 특약 202종(세부 296개)·별표 40개를 추출해 추가했다(전체 1,753건). 상품 필터에 '또또암'·'또또암간편' 버튼 추가.

- 별표는 이름으로 연결(【별\n표3(…)】처럼 글자가 줄로 끊긴 참조 포함). 구분(암종) 열이 있는 표는 특약 본문의 "○○ 진단시" 목록을 어휘로 삼아 그룹별 코드로 나눔 — 암종별(30종)통합암 2표 각 30그룹 전부 코드 배정(93·116코드).

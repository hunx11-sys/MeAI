# 영업지원도구 6종 — 격투만화 패러디 광고 (30초, 세로 1080×1920)

완성본 : `../meai_tools6_baki_parody_30s.mp4`

| 장면 | 시간 | 내용 |
|---|---|---|
| 1 질문 | 0~6.6초 | "이 영업지원도구 6종의 어디에… 편리하다고 생각하나?" / "뭐… 그냥 업무 좀 편하게 해주는 거 아닌가요?" |
| 2 도구 6종 | 6.6~11.6초 | 도구 화면이 와인병처럼 가득, 하나씩 빠르게 → "영업지원도구 6종." → 정적 |
| 3 극한 클로즈업 | 11.6~16.6초 | "편리함도 겨우 14~15배." → "빠르다고 해봐야 겨우 11~12배." |
| 4 좌우 대결 | 16.6~23.6초 | 약관 찾는 쪽 1건 vs 도구 쓰는 쪽 10건 → 정적 → "영업지원도구 6종!" → "영업은 시간이 아니라 기회를 만드는 일입니다." |
| 5 엔딩 | 23.6~30초 | 6개 도구가 한 화면으로, 고객 발견 → 고객 분석 → 상품 확인 → 비교 → 전략 수립 → 상담 → 엔딩 문구 · 문의 |

- 원작 만화의 그림은 쓰지 않았다. 구도와 대사 흐름만 빌리고, 인물(A : 불꽃 갈기머리·괴물 같은 목의 「지상 최강」형 선배 · B : 은발 콧수염 노신사 — 원작 인물 디자인을 베끼지 않고 분위기만 따름)은 `chars.py` 로 새로 그렸다.
  각진 턱·굵은 목·작은 눈동자·깊은 주름·반쪽 그늘을 SVG 로 그리고, `gek.py` 가 그늘을 펜 빗금(최대 3겹)으로 바꾼 뒤 손맛 나는 먹선을 얹는다.
  클로즈업과 「영업지원도구 6종!」 장면은 애니메이션판처럼 붉은 조명을 입혔다.
  인물 다시 그리기 : `python3 chars.py` → A_stern · A_glare · A_grin · B_calm · B_shock.png
- 배수(14~15배·11~12배·1건 대 10건)는 패러디 연출용 **가정값**이다. 화면에 「※ 패러디 연출 · 수치는 가정값」으로 표기했다.
- 배경음은 `music.py` 로 직접 합성했다(저작권 걱정 없음).

다시 만들기 (이 폴더에서)
```
python3 music.py music.wav
python3 render.py "$(pwd)"        # frames/ 에 900장 (frames 폴더를 먼저 만든다)
ffmpeg -framerate 30 -i frames/%04d.jpg -i music.wav -c:v libx264 -crf 25 -pix_fmt yuv420p -c:a aac -shortest out.mp4
```

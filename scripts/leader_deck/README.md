## 순서

```
W=<작업폴더>; mkdir -p $W/cap $W/out
(cd $W && mkdir node && cd node && npm init -y && npm install pptxgenjs@3.12.0 && npm pack pretendard@1.3.9 && tar xzf pretendard-1.3.9.tgz)
node scripts/leader_deck/cap_idx.js $PWD/index.html $W/cap/index.png
NODE_PATH=$W/node/node_modules:$NODE_PATH node scripts/leader_deck/build_leader.js $W $W/node/package/dist/web/variable/woff2/PretendardVariable.woff2 $W/out
python3 scripts/flywheel_deck/make_pdf.py $W/out/meai_leader_2611_files.json $W/out/meai_leader_2611.pdf
```

- `build_leader.js` 는 굽고 나서 「글꼴 · 깨진 그림 · 점검(장 밖으로 나감 · 글 상자 겹침)」을 출력한다. 모두 0 이어야 한다.
- 발표자 메모 첫 줄 `[0:12]` 이 진행 시각이다. 장을 넣고 빼면 시각도 같이 고친다.

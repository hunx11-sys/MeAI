공통 원칙

- 오글거림 줄이기(소유자 요청) : 편지 · 왕관 · 명패 연출, 이모지 그림은 쓰지 않았다
- 그림 : 실제 MeAI 화면은 `guidebook_v4/captures`(가이드북 원본 캡처, 이름 · 숫자는 예시). 질병통계 그래프 481장 · 의학 그림 223장 벽, 통계 그래프 · 의학 카드 예시는 기존 FM 교안 33~36장에서 잘라 `assets/` 에 둠. 영업지원도구 화면은 `cap_tools.js`(대문 · 특약검색기 · 상급종합 지도 · 상품 히스토리 · 보상시뮬레이터 · 통합치료비)
- 숫자 : 전부 기존 두 교안과 MeAI 활용 가이드북에 있는 값(장마다 출처 줄). 「2시간 ÷ 15명 = 8분」 · 일과 시간 · 두 번의 벽 곡선 · 90일 곡선 · 훈련표 · 12차월 지도는 예시 · 개념도 · 제안이라고 장에 적었다
- 일과 시간 : 조회 09:30 · 동행(방문) 전 10분 11:00 · 점심 후 13:00 · 거절 복기 15:00 · 마감 18:00 · 금요일 리플레이(소유자 2026-11-08 : 08:30 → 09:30, 10:00 → 11:00)
- 기존 FM 교안의 '갑상선암 통계 보여줘 → 10명 중 7명은 5년 이상 생존'은 그래프가 암 전체(5년 상대생존율 73.7%)라서 '암 생존율 통계 보여줘 → 암환자 10명 중 7명은 5년 이상 생존합니다'로 맞췄다

## 「의료보험 개혁에 나선 일본」 (서울중앙본부 정보미팅, 약 18분)

- 양식 : 권혁준 양식(보장분석 교안 : 검은 바탕 · 가운데 큰 글자 · 빨간 강조 상자 · 노란 숫자 · 위 제목 밑줄). 이 자료만 노랑 `#FFC21A` · 빨강 `#F2131B`(`kit.build` 의 `css` 로 덧붙임)
- 원재료 : 소유자의 본부 단톡 월요 시사조회(슈카월드 영상 화면 + 소유자 요약). **영상 화면 · 인물 사진 · 기사 사진은 쓰지 않고** 그래프를 새로 그렸다
- 숫자를 출처로 다시 확인하고 바로잡은 것(2026-11-09)
  - 일본 의료비 49.2조 엔 : '예상'이 아니라 후생노동성 2025년도 개산의료비 속보(2026.8.28)로 확정된 숫자
  - '75세 이상이 65~75세 미만의 4배' → 원 보도는 **75세 미만**과 비교(98만 9천 엔 vs 26만 1천 엔, 3.8배)
  - '10월 30일 후생노동상 경고' 인용은 원문을 찾지 못해 2026.3 참의원 후생노동위원회 소신 표명("공적 의료보험을 지키고 다음 세대에 넘기려면 끊임없는 개혁") 보도로 바꿈
  - 본인부담 원칙 30% 는 재정제도심의회(재무성 자문기구) **건의**(2026.4.28 · 6.26)이고 확정 아님. 후생노동상은 2025.11 "일률 30%는 현실적이지 않다"
  - 2027년 예산안 : 총지출 820.9조 원(93조 원 · 12.8% 증가)은 맞지만 총수입은 880.8조 원 전망이라 **'예상 세수 600조, 221조 적자'는 틀린 계산** → 쓰지 않음
  - '투표 인구의 50%가 65세', '한국 제도와 90% 흡사', 한국 30% 시점 2033/2035 혼재 → 숫자 없이 쓰거나 통계청 전망(2030 25.5% · 2040 34.4%, 30%는 2035년 무렵 어림)으로 맞춤
- 말투 : 단톡의 거친 표현은 "내가 권하지 않으면, 내 고객의 노후 병원비는 누가 준비합니까"로, "나라 믿지 마"는 고객 화법에서 쓰지 않는 말로 돌렸다(금융소비자보호법 제21조 : 불확실한 사항 단정 금지). '달러 자산' 이야기는 FP 정보미팅 주제가 아니라 넣지 않았다

## 순서

```
W=<작업폴더>; mkdir -p $W/cap $W/out
(cd $W && mkdir node && cd node && npm init -y && npm install pptxgenjs@3.12.0 && npm pack pretendard@1.3.9 && tar xzf pretendard-1.3.9.tgz)
node scripts/leader_deck/cap_tools.js $W/cap                      # 대문 · 특약검색기 · 지도 · 히스토리 · 보상시뮬 · 통합치료비
F=$W/node/package/dist/web/variable/woff2/PretendardVariable.woff2
NODE_PATH=$W/node/node_modules:$NODE_PATH node scripts/leader_deck/build_leader.js $W $F $W/out
NODE_PATH=$W/node/node_modules:$NODE_PATH node scripts/leader_deck/build_fm.js $W $F $W/out
NODE_PATH=$W/node/node_modules:$NODE_PATH node scripts/leader_deck/build_info_japan.js $W $F $W/out
python3 scripts/flywheel_deck/make_pdf.py $W/out/meai_leader_2611_files.json $W/out/meai_leader_2611.pdf
python3 scripts/flywheel_deck/make_pdf.py $W/out/meai_fm_2611_files.json $W/out/meai_fm_2611.pdf
python3 scripts/flywheel_deck/make_pdf.py $W/out/seoul_info_japan_2611_files.json $W/out/seoul_info_japan_2611.pdf
```

- 굽고 나면 「글꼴 · 깨진 그림 · 점검(장 밖으로 나감 · 글 상자 겹침)」을 출력한다. 모두 0 이어야 한다.
- 발표자 메모 첫 줄 `[0:12]` 이 진행 시각이다. 장을 넣고 빼면 시각도 같이 고친다.
- `cap_idx.js` 는 대문 한 장만 찍는 예전 도구(`cap_tools.js` 가 대문도 찍는다).

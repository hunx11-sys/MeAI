스마트 제안서 생성 — 연동 데모

가입설계서 PDF(설계 시스템에서 「PDF 저장」으로 받은 원본)를 올리면 그 자리에서 가입담보를 읽고 계산해 제안서를 만듭니다. GA 새 양식(2026-11-11 회의 · 15~19쪽)이 기본이고, 기존 GA 6쪽 · 9쪽 지면도 함께 만들 수 있습니다. 프론트엔드는 이 화면이 호출하는 API 를 그대로 쓰면 됩니다.

이 파일을 직접 열면 동작하지 않습니다

이 화면은 파이썬 서버가 켜져 있어야 동작합니다. 아래 순서로 하세요.

  1. proposal_smart 폴더의 start_windows.bat 을 두 번 누릅니다(맥·리눅스는 start.sh).
  2. 검은 창이 열리고 스마트 제안서 API … http://127.0.0.1:8080 이 보이면 준비된 것입니다.
  3. 브라우저 주소창에 http://127.0.0.1:8080 을 입력해 그 화면에서 PDF를 올립니다.

이미 서버를 켜 두셨다면 아래 'API 주소'가 맞는지 확인하고 연결 확인을 누르세요.

    프론트엔드 연동 방법
    

      PDF 바이트를 그대로 POST 하면 됩니다. 별도 인증·LLM 호출은 없습니다.
      서버는 python api.py 로 띄웁니다(추가 패키지 설치 없음).


// ⓪ GA 새 양식 — PDF 만 받기 / 요약 · 로그 · PDF(base64) 한 번에 받기
const ga2 = await fetch(API + '/v1/ga2/pdf',
  { method:'POST', headers:{'Content-Type':'application/pdf'}, body: file }).then(r => r.blob());
const ga2all = await fetch(API + '/v1/ga2/all',
  { method:'POST', headers:{'Content-Type':'application/pdf'}, body: file }).then(r => r.json());
// ga2all.pages / ga2all.care_pages(['support'|'use'|'none']) / ga2all.log / ga2all.pdf_base64

// ① 결과 PDF 만 받기
const pdf = await fetch(API + '/v1/proposal/pdf',
  { method:'POST', headers:{'Content-Type':'application/pdf'}, body: file })
  .then(r => r.blob());

// ② 요약 · 감사로그 · 지면 HTML · PDF(base64) 한 번에 받기
const data = await fetch(API + '/v1/proposal/all',
  { method:'POST', headers:{'Content-Type':'application/pdf'}, body: file })
  .then(r => r.json());
// data.total_pages / data.new_pages / data.audit / data.pages_html / data.pdf_base64


## 2. 입력 (customer.json)
```json
{"insured":"고객님","premium":"215,560원","product":"(무)메리츠 The건강한 내Mom대로 …","head":"계약사항 : …",
 "agent":"OO본부(O지점) … | 담당자(고유번호 : …)","issued":"2026.09.14 20:54:02<br>담당자",
```

`riders`가 없으면 `matcher.read_proposal(원본.pdf)`이 가입담보리스트 **표를 셀 단위로** 읽어 자동 생성한다(2줄로 접힌 갱신형 간병 담보도 누락 없음 · 40M 70건 / 40F 66건 인식).
`insert_after`·`base_pages`는 build_all이 원본 PDF에서 자동 판단한다('보장보험료 합계' 마지막 출현 쪽).

## 3. 담보명 정규화·매칭 (matcher.py)
고지유형 꼬리표 `(건강가입)/(통합간편가입)/(355간편가입)/…` 제거(목록은 **`rules.json goji_tags` 한 곳**에서 관리 — v8.3) → 완전일치 → `[세부급부]` 분리 →
말미 `(하위그룹)` 분리 → 괄호 전부 제거 → 최장 접두 일치. 특약 마스터 `db.json`(951건).
**v4.0** : 특약 마스터를 특약검색기(tool.html, ver2609)에서 재추출 — 951담보 · KCD 11,506건(범위표기 `A15~A19` 포함, 이전 판보다 약 40% 증가)·별표 연결정보 포함.
`(20년갱신)` 등 갱신주기 접두어도 정규화 대상에 추가.
검증 : 40세남성 통합간편 설계 70담보 **68건 자동 매칭(97.1%)** — 미매칭 2건은 마스터 미수록 신담보이며 규칙표로 지급 판정은 정상 수행.

지급 빈도 once/year/each → 매트릭스 3행(최초·반복·매회) 계산.

**④ 보수적 지급 조건(조건부 담보) — v5.0**
약관상 **두 가지 치료를 모두 받아야** 또는 **약물종류가 몇 종 이상이어야** 지급되는 담보는 조건을 충족한 경우에만 계산한다.

| 담보 | 약관 조건 | 규칙표 표기 |
|---|---|---|
| 뇌혈관질환·허혈성심장질환 **특정혈전치료비** | 연간 1년 이내 「혈전용해치료」와 「급여 기계적혈전제거술(카테터법)」을 **각각 1회씩 모두** 받은 때 연간 1회 | `acts_all: [thromb, thrombectomy]` — 한 가지만 받은 단계에서는 0원 |
| **표적항암약물허가치료비(2종 및 3종 이상)** | 연간 사용한 **표적항암제 약물종류가 2종 이상**일 때 각각 연간 1회 | `need_drug: 2` — 1종만 사용한 사례에서는 0원 |
| 암·유사암 **통합치료 생활비** | 연간 통합치료 **2회 이상** | `need_cnt: 2` |

사례(플로우)에서는 앞 단계에서 이미 받은 치료를 `done` 태그로 넘겨, **혈전용해(STEP2) → 혈전제거술(STEP3)** 처럼 단계가 나뉘어도 조건 충족 시점에 한 번만 지급되도록 했다(중복 지급 없음).
또한 **특정혈전치료비를 진단비로 합산하던 오류를 수정**했다 — 뇌혈관·허혈성심장 진단금은 각 담보의 진단비 가입금액만 표기된다(예 : 2,000만원 + 2,000만원 → 각 2,000만원).

**질병코드 지도(4쪽)의 판정 근거** — 뇌출혈/뇌졸중/뇌혈관질환/급성심근경색/허혈성심장 진단비와 산정특례 진단비는 특약 마스터(db.json)의 약관 KCD 목록, 특정순환계질환 통합치료비는 `EMB.c32`(52개 질병), 특정순환계질환(주요손상및질환) 통합치료비는 `EMB.m61`(40개 질병)을 그대로 사용한다. 질병명은 `kcdnames.json`. 칸 색은 **그 질병코드를 보장하는 가장 좁은 담보**이며, 회색 칸은 어느 담보로도 보장되지 않는 질병이다.

**⑤ 병원 종별 포함관계 · 한도일수 (v6.0)**
상급종합병원은 의료법 제3조의4에 따라 **종합병원 중에서** 지정되므로, 상급종합병원 입원·수술 시 **종합병원 조건 담보도 함께 지급**한다(`hosp_ok`, 의원<병원<종합<상급종합). 입원일당은 담보마다 **한도일수를 개별 적용**한다.
예) 1인실 상급종합 11만원(10일 한도) + 1인실 종합 10만원(30일 한도), 14일 입원 → 110만원 + 140만원 = **250만원**.
간호·간병통합서비스는 하루 7만원 × 14일 = **98만원**으로 일수를 곱해 표기한다.

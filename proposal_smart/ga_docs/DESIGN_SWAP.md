# 디자인만 바뀔 때 — GA 새 양식(v2) 디자인 교체 절차

세일즈혁신TF · 2026-11-20. 「표와 구조는 그대로, 디자인만 변경」 일 때의 순서입니다. 계산 · 칸 값 · 규칙은 건드리지 않습니다.

## 1. 디자인과 계산은 파일이 나뉘어 있습니다

| 구분 | 파일 | 디자인 교체 때 |
|---|---|---|
| 계산 | `scen_engine.py` · `rules.json` · `ga_spec.py`(칸 정의 · 사례) · `ga_care.py` · 특약 마스터 | **손대지 않음** |
| 지면에 무엇을 적나 | `ga_v2.py` 의 칸 값 읽기 · 수술 카드 줄 · 간병인 표 | 표 · 구조가 같으면 손대지 않음 |
| 암 ① ② · 뇌혈관 · 심장 · 안내사항 · 세부내역 머리 | `ga_assets/v2/tpl.pdf`(빈 틀) · `slots.json`(값 자리 좌표 · 글자 크기 · 색) | 새 시안으로 다시 굽기 |
| 주요수술 ① ② · 간병인 · 세부내역 표 | `ga_assets/v2/v2.css` · `icons/` · `ga_v2.py` 의 고정 문구 | CSS · 그림 · 문구 |
| 표지 · 보장요약 | `ga_assets/mock/` 가안 그림 · `overlay_p0.json` · `overlay_p1.json`(값 상자 좌표) | 그림 · 좌표 |
| 글꼴 | `ga_assets/noto/` · Pretendard | 시안 글꼴에 맞춤 |

## 2. 순서

1. **새 시안 PDF 받기** — 개인정보(설계사명 · 설계번호)가 있으므로 저장소 밖 작업 폴더에 둡니다.
2. **틀 다시 굽기**(암 ① ② · 뇌혈관 · 심장)
   ```
   cd proposal_smart
   cp ga_assets/v2/tpl.pdf <작업폴더>/old_tpl.pdf ; cp ga_assets/v2/slots.json <작업폴더>/old_slots.json
   python ga_v2_template.py <새 시안.pdf> <작업폴더>/old_tpl.pdf <작업폴더>/old_slots.json
   ```
   - 시안 쪽에서 예시 값 글자만 지우고 빈 틀로 만듭니다. 값 자리(`slots.json`)는 지운 글자의 자리 · 크기 · 색에서 얻습니다.
   - 개인정보 · 숨은 글자 · 남은 예시 값이 있으면 굽는 도중 멈춥니다.
   - 시안의 쪽 순서나 값 개수가 달라졌으면(= 구조 변경) 여기서 멈춥니다 → 4장.
3. **HTML 쪽**(주요수술 · 간병인 · 세부내역) — `v2.css` 의 치수 · 색 · 글꼴, 아이콘 그림, 고정 문구를 시안에 맞춥니다.
4. **표지 · 보장요약** — 가안 그림을 바꾸고, 값 상자 좌표가 옮겨졌으면 `overlay_p1.json` 을 맞춥니다.
5. **검증(반드시)**
   ```
   python verify_v2.py <설계서 폴더>        # 전부 통과 = 값이 제 자리에 제 값으로 찍힘
   ```
   - 디자인 교체 전에 `<설계서 폴더>` 로 한 번, 교체 뒤에 한 번 돌립니다. 대조 곳 수가 같고 전부 통과면 값은 그대로입니다.
   - 쪽이 넘치거나 글자가 칸 밖으로 나가면 생성 로그 「지면 경고」 에 나옵니다(0 이어야 함).
6. **눈으로 보기** — 시안과 같은 설계(남 28세 95,538원)로 만든 PDF 를 시안과 나란히 놓고 봅니다.
7. **기록 · 묶음** — `README.md` 변경 기록(계산 변경 없음) · `python3 scripts/build_ga_v2_package.py`.

## 3. 디자인 교체로 달라지면 안 되는 것(검증 도구가 보는 것)

- 보장요약 칸 값 · 암 · 뇌 · 심 값 자리 118개의 글자
- 수술 카드 12장의 머리 금액 · 다섯 줄(줄 이름 · 금액 · 미가입 · 해당 없음) · 카드 합계 = 보장요약 칸
- 간병인 표 칸 글자(1~180일 = 보장요약 간병인 칸)
- 세부내역의 구분 보장금액 · 가입금액 · 특약별 보장금액 순서와 합계

## 4. 이것은 「디자인만」 이 아닙니다(구조 변경)

아래는 계산 쪽(칸 정의)과 설계도까지 같이 바꿔야 합니다. 약관 · GA 확정이 먼저입니다.

- 칸을 더하거나 뺌(예 : 수술 카드 수술 종류 변경 · 암 검사 종류 추가)
- 수술 카드 줄 수 · 줄 묶는 기준 변경
- 간병인 표의 행 · 열 변경
- 사례(질병코드 · 수술 · 병원 종별) 변경

고치는 곳 : `ga_spec.py`(칸) → `ga_v2.py`(지면) → `slots.json` → 설계도 3종 다시 뽑기 → `verify_v2.py`.

# MeAI 영업지원도구 디자인 규칙

영업지원도구 7개 화면(대문 · 특약검색기 · 보상시뮬레이터 · 상품 라인업 · 통합치료비 시뮬레이터 · 프롬프트 라이브러리 · 명패 제작기 · 사용 통계)이
**하나의 규칙**으로 보이게 하는 문서다. 바탕은 토스(흰 캔버스 · 차가운 회색 · 한 화면 한 강조색 · 큰 둥근 모서리 · 1px 실선 · 해요체)이고,
한글 본문 · 표 · 접근성은 대한민국정부(KRDS), 촘촘한 정보 화면의 표 · 칩 · 탭 · 초점은 Apple · Meta · Figma · Nike · Airtable 의 공통 원칙을 따랐다.
**도구마다 다른 것은 강조색 하나뿐**이다 — 그 도구 걱정인형(마스코트)의 색이다. 나머지는 모두 같다.

공통 스타일 원본은 `ui/meai-ui.css`, 사이트 셸(머리 띠 · 움직임) 원본은 `ui/meai-site.js`, 화면에 넣는 것은 `python3 scripts/apply_ui.py`
(각 HTML 의 `<style id="meai-ui">` · `<script id="meai-boot">` · 머리 띠 `<!--mu-nav-->` · `<script id="meai-site">` 를 바꿔 끼운다).

## 1. 색

### 도구별 강조색 (마스코트 색 · 흰 바탕 글씨 대비 4.5:1 이상)

| 도구 | 마스코트 | `--accent` 채움 | `--accent-on` 채움 위 글씨 | `--accent-strong` 글씨·선 | `--accent-weak` 연한 바탕 | `--accent-line` 연한 선 |
|---|---|---|---|---|---|---|
| 대문 · 사용 통계 (`home`) | — (메리츠) | `#C8102E` | `#FFFFFF` | `#A50D26` | `#FDECEE` | `#F5C2CA` |
| 특약검색기 (`merry`) | 메리 · 주홍 | `#C73D1C` | `#FFFFFF` | `#B5361A` | `#FDEEE9` | `#F6CBBD` |
| 보상시뮬레이터 (`eco`) | 에코 · 초록 | `#23874C` | `#FFFFFF` | `#1A6B3C` | `#E9F6EE` | `#BFE3CC` |
| 상품 라인업 (`rara`) | 라라 · 황금 | `#F2B705` | `#3D2C00` | `#8A6000` | `#FFF6D6` | `#F3DD94` |
| 프롬프트 라이브러리 (`indi`) | 인디 · 자주 | `#A23A91` | `#FFFFFF` | `#7E2C72` | `#F8ECF5` | `#E8C3DF` |
| 명패 제작기 (`tata`) | 타타 · 파랑 | `#2563C9` | `#FFFFFF` | `#1B4C9C` | `#EAF1FC` | `#C3D6F4` |
| 통합치료비 시뮬레이터 (`zizi`) | 찌지리 · 연보라 | `#6D5BD6` | `#FFFFFF` | `#5242AE` | `#F0EEFC` | `#D3CCF5` |

- 강조색은 화면의 10% 안쪽. **채움**은 그 화면의 주 버튼 하나 · 선택된 단계 · 켜진 스위치에만. **진한 글씨색**은 링크 · 선택된 탭 글씨 · 강조할 숫자 하나. **연한 바탕**은 선택된 칩 · 선택된 줄 · 안내 상자.
- 강조색을 화면 바탕 · 제목 · 표 테두리에 쓰지 않는다. 오류 표시에 강조색을 쓰지 않는다(빨강 `--danger` 는 따로).
- 대문은 카드마다 그 도구의 강조색을 아이콘 칩 · 태그에만 쓴다(도구를 알아보는 표지 — 장식 줄 · 그러데이션 금지).

## 2. 글꼴

- **Pretendard Variable** 하나만 쓴다(토스 전용 서체의 공식 대체 · KRDS 기본 서체). 숫자는 `font-variant-numeric: tabular-nums`(금액 · 코드 · 표).
- 폐쇄망 배포판은 `scripts/build_package.py` 가 `assets/pretendard-subset.woff2` 를 파일 안에 심는다 — 화면은 `"Pretendard Variable"` 을 쓰기만 하면 된다.
- 고정폭(코드) 글꼴은 질병코드 · 수가코드를 칩으로 보일 때만: `--mono: "SF Mono", "Consolas", "D2Coding", monospace`.
- 이모지는 문장 안에 섞지 않는다. 기능 아이콘 칩 · 빈 화면 그림으로만.

| 이름 | 크기/줄간격 | 굵기 | 자간 | 쓰임 |
|---|---|---|---|---|
| display | 32/1.3 (휴대폰 26) | 700 | -0.02em | 화면 머리 제목 |
| h1 | 24/1.3 | 700 | -0.02em | 구역 제목 · 모달 제목 |
| h2 | 20/1.35 | 700 | -0.015em | 카드 묶음 제목 |
| h3 | 17/1.45 | 600 | -0.01em | 카드 제목 |
| body | 15/1.6 | 400 | 0 | 기본 글 |
| body-long | 16/1.7 | 400 | 0 | 약관 본문 (`word-break: keep-all`) |
| table | 14/1.5 | 400 | 0 | 표 칸 |
| label | 14/1.25 | 600 | 0 | 버튼(M) · 탭 |
| caption | 13/1.45 | 500 | 0 | 설명 · 칩 |
| micro | 12/1.4 | 600 | 0 | 배지 — **12px 미만 금지** |

- 강조는 크기와 색으로 먼저, 굵기는 400 · 600 · 700 세 단계만. 800 이상 쓰지 않는다.
- 금액은 **숫자 굵게 · 단위 보통**(「**3,000**만원」, 쏘카). 대문자 · 넓은 자간 · 느낌표 제목을 쓰지 않는다.
- 한글 문단은 `word-break: keep-all; overflow-wrap: anywhere`.

## 3. 간격 · 크기

- 4px 단위: 4 · 8 · 12 · 16 · 20 · 24 · 32 · 40 · 48 · 64.
- 화면 좌우 여백: 휴대폰 16, PC 24~32. 본문 최대 폭 1200px.
- 누르는 것은 **최소 44×44px**(작은 칩은 위아래 여백으로 맞춘다). 입력칸 높이: PC 44, 휴대폰 48.
- 한 단위 간격 규칙: 묶인 요소 8 · 같은 무리 12~16 · 무리 사이 24 · 구역 사이 40~48.

## 5. 깊이 (그림자는 떠 있는 것에만)

- 기본은 평면 + 1px `--line`. 회색 바탕 위 흰 카드는 테두리 없이도 된다.
- `--sh-1: 0 1px 2px rgba(15,23,42,.04), 0 1px 1px rgba(15,23,42,.04)` — 세그먼트 선택 알약
- `--sh-2: 0 4px 12px rgba(15,23,42,.06), 0 1px 2px rgba(15,23,42,.04)` — 펼침 목록 · 떠 있는 버튼
- `--sh-3: 0 12px 32px rgba(15,23,42,.12), 0 2px 6px rgba(15,23,42,.06)` — 모달
- 바텀시트: `0 -2px 12px rgba(15,23,42,.06)` · 덮개(스크림) `rgba(0,0,0,.5)`
- 안쪽 그림자 · 그러데이션 · 2px 장식 테두리 · **왼쪽 색 띠 카드 금지**.

## 6. 움직임

- 화면 안 부품 : `--ease: cubic-bezier(.22,.61,.36,1)` · 누름 120ms · 바뀜 200ms · 시트/모달 240ms. 튕김 · 깜빡임 · 반짝임(shimmer) 금지.
- 누르면 `scale(.98)`(버튼 · 카드만). PC 에서 마우스를 올리면 바탕색만 바뀐다 — 단, 「11. 사이트 셸」이 정한 카드는 2px 떠오른다.
- 화면 사이 · 들어올 때 · 스크롤해 보일 때의 움직임은 「11. 사이트 셸 · 움직임」의 스프링 곡선을 쓴다.
- `prefers-reduced-motion` 이면 움직임을 끈다.

## 7. 부품

| 부품 | 규칙 |

| 보조 버튼 | `--surface-2` 채움 + `--ink` 글씨. 약한 버튼은 바탕 없이 `--accent-strong` 글씨. |
| **검색창** | 높이 48(PC 44~48), 모서리 12, `--surface-2` 채움 · 테두리 없음, 왼쪽 돋보기. 초점: 흰 바탕 + 1.5px `--accent` 테두리 + 3px `--accent-weak` 고리. 지우기(×) 단추. 안내 글은 질문형(「어떤 특약을 찾으세요?」). |
| **칩(필터)** | 높이 36, 알약, 1px `--line` + 흰 바탕, 13~14px 500. 선택: `--accent-weak` 바탕 + 1px `--accent-line` + `--accent-strong` 글씨 600. 한 줄 · 넘치면 휴대폰은 옆으로 밀기. |
| **세그먼트** | `--surface-2` 바탕 + 모서리 12, 선택은 흰 알약 + `--sh-1` + `--ink` 600. 서로 바꾸는 보기 전환에. |
| **탭** | 글씨 탭 + 선택 시 2px `--accent` 밑줄 · `--ink` 700, 나머지 `--muted` 500. 줄 전체 아래 1px `--line`. 모달 안에서는 세그먼트. |
| **카드** | 흰 바탕, 1px `--line`, 모서리 16, 안쪽 20(휴대폰 16), 그림자 없음. 선택된 카드만 1.5px `--accent` 테두리. |
| **배지** | 높이 22, 12px 600, 모서리 6, 연한 바탕 + 같은 색 진한 글씨(의미색 또는 강조색). |
| **표** | 감싸개 1px `--line` 모서리 12 + 넘치면 그 안에서만 가로 밀기. 머리: `--surface-1` 바탕, 13px 600 `--sub`, 아래 1px `--line-strong`. 칸: 14px, 위아래 10~12 · 좌우 12~14, 줄 구분 1px `--line-soft`, **세로선 없음**. 금액 오른쪽 맞춤 + 자릿수 맞춤 숫자. 합친 칸은 `--surface-1`. |
| **모달** | 폭 560~760(넓은 표는 960), 모서리 20, 안쪽 24, `--sh-3`, 덮개 50%. 머리는 위에 붙고 아래 1px 선. **휴대폰은 바텀시트**(위 모서리 24 · 손잡이 36×4). Esc · 바깥 누르면 닫힘. |
| **알림(토스트)** | `--ink` 바탕 + 흰 14px 500, 모서리 12, 아래 가운데, 2.5~3초, 한 번에 하나. 완료는 초록 체크. |
| **빈 화면** | 일부가 비면 회색 13px 한 줄. 전체가 비면 마스코트 + 이유 한 줄 + 다음 행동 버튼 하나(보조 버튼). |
| **숫자 타일(통계)** | 숫자 28~32/700 자릿수 맞춤 + 단위 보통 + 13px `--muted` 이름. 출처나 「가정값」 표시. |
| **차트** | 강조 계열 하나만 `--accent`, 비교는 회색, 축선 없음, 그러데이션 없음. |
| **초점(키보드)** | 모든 누르는 요소 `:focus-visible` → 2px `--accent` 바깥선 + 2px 띄움. `outline:none` 만 두지 않는다. |

## 8. 글(말투)

- 화면 글은 **해요체**: 「검색 결과가 없어요」 「복사했어요」. 약관 인용 · 면책 · 정책 문구만 합니다체.
- 버튼은 일어날 일을 그대로: 「비교하기」 「복사하기」 「인쇄하기」. 12글자 이하.
- 「저희」 「우리」 대신 주어를 빼거나 「세일즈혁신TF」. 과장(「혁신적」 「최고의」) · 느낌표 · 문장 중간 긴 줄표(—) 금지.
- 사용자 것은 「내 …」(「내 통합치료비 조합」).

## 9. 휴대폰 · PC

- 나뉘는 폭: 640(휴대폰) · 1024(PC). 휴대폰은 한 줄 배치, 모달 → 바텀시트, 필터는 옆으로 밀기, 표는 감싸개 안 가로 밀기.
- 마우스 올림 효과는 PC 만(`@media (hover:hover)`), 누름 효과는 휴대폰.
- 화면 아래 고정 버튼은 높이 56 + 안전 여백(`env(safe-area-inset-bottom)`).

## 10. 하지 않는 것 (모아 보기)

그러데이션 바탕(사이트 셸의 맨 위 바탕 빛 하나만 예외) · 왼쪽 색 띠 · 2px 장식 테두리 · 안쪽 그림자 · 강조색 두 개 이상 · 순검정 글씨 · 12px 미만 글씨 · 800 이상 굵기 ·
대문자 · 느낌표 제목 · 문장 속 이모지 · 튕기는 움직임 · 320ms 넘는 페이드(사이트 셸의 들어올 때 · 스크롤 올라오기 · 메뉴 시트는 예외, 11장) · `outline:none` 만 · 세로선 많은 표 · 색만으로 뜻 전달.

## 11. 사이트 셸 · 움직임

7개 화면이 **한 사이트**로 이어져 보이게 하는 공통 틀이다. 원본은 `ui/meai-ui.css`(맨 아래 「사이트 셸」 구역) · `ui/meai-site.js`,
화면에 넣는 것은 `python3 scripts/apply_ui.py`. 바깥 파일(CDN · 아이콘 글꼴 · 라이브러리)을 쓰지 않는다 — 폐쇄망 · 올인원에서도 그대로 돈다.

### 머리 띠 (`#mu-nav`)

| 항목 | 규칙 |
|---|---|
| 자리 | `<body>` 바로 뒤, `position:sticky; top:0`, 높이 `--mu-nav-h` = 56px, `z-index:45` — 화면의 붙박이 머리(30~40)보다 위, 모달 덮개 · 시트(50 이상)보다 아래 |
| 겉모습 | 반투명 흰색(.78) + `backdrop-filter: saturate(180%) blur(18px)` + 아래 1px 머리카락 선. 스크롤하면 그 도구 색이 아주 옅게 섞인 그림자(`html.mu-scrolled`) |
| 왼쪽 | 표지 「M」(메리츠 빨강 28px) + **MeAI** 영업지원도구 (1080px 이하에서는 「MeAI」만) |
| 링크 | 대문 · 특약검색기 · 보상시뮬레이터(`tool.html#sim`) · 상품 라인업 · 통합치료비 · 프롬프트 · 명패. 앞에 마스코트 색 점 6px. **사용 통계는 넣지 않는다**(인터넷판 전용) |
| 지금 화면 | `aria-current="page"` — 그 도구의 연한 바탕 알약 + 진한 글씨. 마우스를 올리면 알약이 그 링크로 **미끄러진다**(460ms 스프링) |
| 휴대폰(760px 이하) | 표지 + 지금 도구 칩 + 메뉴 단추(44×44). 단추를 누르면 **아래에서 올라오는 시트**(위 모서리 24 · 손잡이 36×4 · 줄 높이 56 · 마스코트 색 점 · 「지금 화면」 배지). 바깥 · ✕ · Esc 로 닫힘, 시트 안에서만 초점이 돈다 |
| 진행 막대 | 화면 높이의 2.5배가 넘는 긴 화면만, 머리 띠 아래 2px 그 도구 색(CSS 스크롤 타임라인 — 지원 안 하면 안 보임) |
| 인쇄 | 머리 띠 · 시트 · 바탕 빛은 인쇄에서 빠진다(명패 인쇄 결과 그대로) |

- 링크는 보통 `<a href="tool.html">` 이다. 배포판의 파일 이름 바꾸기(`build_package` · `build_single`)와 올인원의 링크 가로채기(`build_allinone` NAV)가 그대로 듣는다.
- **붙박이(sticky) 요소는 `top: var(--mu-nav-h, 0px)` 기준으로 둔다.** 지금 맞춘 곳 : 특약검색기 `.rail` · PC 머리(`header`, 1200px 이상) · 보상시뮬레이터 칸막이(`#simFrame`), 통합치료비 · 사용 통계 `.appbar`(휴대폰에서는 붙박이를 풀어 머리 띠만 남긴다).
- 다른 MeAI 화면 안(iframe, 예 : 특약검색기 안의 보상시뮬레이터)에서는 머리 띠를 지운다 — 바깥 화면의 머리 띠가 이미 있다. 각 화면의 「🏠 대문」 단추는 머리 띠로 옮겼다(새로 만들지 않는다).

### 움직임 토큰

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--mu-spring` | `cubic-bezier(.16,1,.3,1)` | 들어올 때 · 미끄러짐 · 시트 · 떠오름 (튕기지 않고 빨리 붙는 곡선) |
| `--mu-t-in` | 560ms | 화면이 들어올 때 : 본문이 12px 아래에서 옅게 올라온다(`html.mu-enter`, 1.4초 뒤 표시 해제) |
| 스크롤 올라오기 | 640ms · 18px · 형제끼리 70ms 간격(최대 5칸) | `[data-reveal]` · 카드(`.cards>.card` · `.card` · `.p` · `.panel` · `.kpis>*`) |
| `--mu-t-hover` | 200ms | 카드 떠오름 `translateY(-2px)` + 그 도구 색이 섞인 그림자, 누르면 `scale(.98)` |
| `--mu-t-sheet` | 520ms | 휴대폰 메뉴 시트 (줄이 35ms 간격으로 따라 올라온다) |
| 모달 덮개 | 280ms 옅게 열고 닫기 | `.ov` · `#hov` · `#mapov` · `#oncoov` · `.modal-overlay` · `#ex-mask` (`@starting-style` · `display` 넘김) |
| 화면 넘김 | 240ms 겹쳐 사라짐 | `@view-transition{navigation:auto}` — 머리 띠는 이름(`view-transition-name: mu-nav`)을 붙여 움직이지 않는다 |

### 스크롤 올라오기 규칙

- **처음 화면에 보이는 것은 숨기지 않는다.** 불러온 뒤 화면 아래에 있는 것만 `.mu-rv` 로 숨겼다가 보일 때 올린다(IntersectionObserver).
- 숨김은 자바스크립트가 붙인 표시(`html.mu-js` + `.mu-rv`)로만 일어난다 — 스크립트가 멈춰도 내용이 사라지지 않는다. 다 올라오면 표시를 지워 마우스 올림 효과가 다시 듣는다.
- 모달 · 시트 · 비교 바 안의 것은 건드리지 않는다. 검색 · 필터로 다시 그린 카드는 그대로 보인다.
- 인쇄 · 움직임 줄이기(`prefers-reduced-motion`)에서는 모두 끈다(스크롤 부드럽게 · 화면 넘김 포함).

### 바탕 빛

- 화면 맨 위 560px 에만 그 도구 색 알파 6~8% 원형 빛 두 개 + 파랑 4% 하나(`#mu-amb`). 글씨 대비에 영향이 없어야 하고, 카드 · 표 안에는 쓰지 않는다.

### 하는 것 · 하지 않는 것

| 하는 것 | 하지 않는 것 |
|---|---|
| 움직임은 `transform` · `opacity` 로만(알약 폭만 예외) | `top` · `left` · `height` 를 움직이기, 무한 반복 장식 움직임 |
| 블러는 머리 띠(붙박이)에만 | 스크롤되는 카드 · 표에 `backdrop-filter` |
| 새 화면도 `apply_ui.py` 목록에 넣어 같은 머리 띠를 받는다 | 화면마다 자기 「대문」 단추 · 자기 위쪽 메뉴를 따로 만들기 |
| 붙박이 머리는 `top: var(--mu-nav-h, 0px)` | `top:0` 그대로 두어 머리 띠 밑에 깔리게 하기 |
| 링크는 평범한 `<a href="파일.html">` | 자바스크립트로 주소를 만들어 이동(올인원 · 배포판 이름 바꾸기가 못 잡는다) |

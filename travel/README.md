# 비짓투재팬 VISIT to JAPAN : 34개 일본 도시 자동 여행 플래너 (travel/)

출발 공항과 박 수만 고르면 **직항편 → 하루하루 동선 → 맛집 → 지도 → 숙소 → 예산 → 대체 동선·대체 여행지**까지 한 화면에서 보여 주는 여행 가이드 프로그램입니다. 일본을 첫 대상으로 만들었고, 같은 틀에 다른 나라 자료를 넣으면 그대로 늘어납니다.

- 인터넷 주소(깃허브 페이지) : **https://hunx11-sys.github.io/MeAI/travel/** (→ `travel/japan.html` 로 넘어감. `main` 에 올리면 몇 분 뒤 자동 반영. 영업지원도구 6종은 저장소 맨 위에 있어 주소가 겹치지 않음. 카카오톡 등에 붙이면 미리보기 그림 `travel/og.png`·설명이 뜨고, 홈 화면에 추가하면 아이콘 `travel/icon-180.png`)
- 다운로드용 한 파일 : **`dist/visit_to_japan_ko_v1.5.html`** (한국어, 언어 버튼 없음. 컴퓨터 브라우저로 열면 지도까지 그대로 동작. 다시 만들 때 `python3 travel/build_japan.py --lang ko --no-lang-menu --out dist/visit_to_japan_ko_v1.5.html`)
- 완성 파일 : **`travel/japan.html`** (한국어, 언어 버튼 없음. 다시 만들 때 `python3 travel/build_japan.py --lang ko --no-lang-menu`. 파일 하나. 아이폰 사파리·크롬·엣지 어디서나 열립니다. 지도 바탕 그림과 글꼴만 인터넷이 필요하고, 나머지는 인터넷 없이도 됩니다)
- 다른 언어 : `japan_en.html`(영어) · `japan_es.html`(스페인어) · `japan_zh.html`(중국어 간체) · `japan_yue.html`(중국어 광동어·번체) · `japan_ja.html`(일본어). **v2 첫 조립(2026-10-15) 그대로라 한국어판보다 옛 판**이어서, 지금은 한국어판에서 지구본 버튼을 감춰 둠(소유자 : 한국어 먼저). 다시 열 때는 각 언어를 새로 조립·점검한 뒤 `--no-lang-menu` 를 빼고 조립
- 자료(데이터베이스) : `travel/data/` 아래 JSON 파일들
- 조립 : 저장소 루트에서 `python3 travel/build_japan.py --lang ko --no-lang-menu` (언어를 빼고 돌리면 다른 언어 파일까지 다시 써지니 주의)

## 화면 흐름 (v1.4 단계형 · 한 화면에 결정 하나)

1. **며칠** (`#home`) : 2박 3일 · 3박 4일 · 4박 5일 큰 카드(달·해 그림). '아직 몰라요'와 바로 찾기(검색), 최근 본 일정 '이어 보기' 카드
2. **출발 공항** (`#from`, 처음 한 번만) : 직항 도시 수가 많은 순서로 큰 버튼
3. **큰 색 지도** (`#map`) : 지역 9개를 서로 다른 색으로 칠한 일본 지도. 지역마다 이름 · 도시 수 알약(한 줄, 누르는 칸 44px). 알약은 땅을 가장 덜 가리는 바다 쪽 자리를 화면 폭마다 자동으로 골라 가는 선으로 잇는다. 고른 공항에서 직항이 없는 지역은 회색 빗금. 아래에 지역 장면 그림 카드 3×3(대표 도시 두 곳)
4. **지역 확대** (`#map/kansai` 등) : 그 지역으로 지도가 커지고 도시 핀·이름. 도시끼리 붙어 있으면(오사카·고베·나라, 후쿠오카·사가) 더 당겨 보고, 이름은 바깥쪽부터 서로·핀·'전체 지도' 단추와 겹치지 않는 자리에 둔다. 오키나와는 본섬 · 야에야마(이시가키) 두 칸으로 나눠 크게. 핀을 누르면 '○○ 일정 보기', 아래 도시 카드(그림 · 성격 한 줄 · 비행시간)
5. **도시 화면** (`#kyoto`, `#kyoto/n3/d2`, `#kyoto/food` …) : 일정 탭은 지역 장면 위 도시 그림, 요약 알약(비행시간 · 박 수 바꾸기 · 1인 예산과 환율 기준). 맛집·볼거리·숙소·준비 탭은 큰 그림 없이 한 줄 머리('교토 맛집 24곳'). 아래 탭 5개
   - 일정 : 대체 플랜 칩 · 일차 탭(화면 위에 붙음, 부제 두 줄) · 하루 지도 미리보기(누르면 큰 지도 시트, 멀리 떨어진 공항은 화면 맞춤에서 빼고 가장자리에 표시) · 일정 행(시각 · 번호 · 그림 · 이름 두 줄까지 · 메모, 꼭 갈 곳은 이름 앞 '꼭', 오른쪽 표는 하나 : 마감 임박 > 입장료 > 무료, 누르면 펼침) · 식사는 고른 식당 하나 + '후보 n곳'(그림 카드로 고르는 시트) · 비 오면? · 비슷한 다른 곳
   - 맛집 : 음식 종류 칩(음식 그림, 옆으로 미는 한 줄) + 2열 그림 카드(같은 그림이 이어지면 뒤집거나 당겨서 다르게) · 볼거리 : 분류 칩 + 2열 · 숙소 : 카드 · 준비 : 예산 막대(환율 바꾸기) · 항공편 · 공항에서 시내 · 준비물 체크 · 추천 시기 · 이동 요령 · 참고 자료
6. 검색(`#search`) · 모든 도시 한눈에(`#all`, 테마 칩)
- 자세한 내용은 아래에서 올라오는 시트로 보여 주고, 뒤로 가기(아이폰 밀기·안드로이드 뒤로)를 누르면 시트만 닫힌다. 화면 이동만 기록에 쌓고, 일차·탭·박 수 바꾸기는 주소만 바꾼다. 예전 링크(`#kyoto`)도 열린다
- 설계 근거 : `travel/docs/ux_v2/`(설계안 3개 · 인수인계). 점검 스크립트 : `travel/tools/qa/`

고른 출발 공항·박 수·식당 선택·체크 표시는 그 기기 안에만 저장됩니다(서버 없음).

목적지마다 **특징·장점 해시태그**(예 : #공항에서 도심 40분, #우동 한 그릇 500엔)가 알록달록한 칩으로 카드와 상단에 붙습니다. 자료의 `highlights` 항목입니다.

## 자료는 어디서 왔나

| 파일 | 내용 | 만든 방법 |
|---|---|---|
| `data/jp_airports.json` | 일본 공항 전부와 한국 출발 직항 노선(항공사·비행시간·주 횟수·정기/계절/전세·출처 URL) | 일본 지역별 6명 + 한국 공항별 1명이 웹을 조사 → 공항마다 회의론자 1명이 노선 하나하나 반박 시도 → 한국 공항별 조사에만 있던 노선은 따로 검증. 정리 규칙은 `tools/merge_flights.py` 맨 위에 적어 둠 |
| `data/guides/<목적지>.json` | 목적지 하나의 명소·식당·숙소·공항 교통·박 수별 플랜·대체 동선·플랜 B·대체 여행지·예산·준비물 | 목적지마다 조사(장소) → 설계(동선) → 검증(회의론자가 폐업·휴무·좌표·동선 반박) → 정정의 4단계. 소유자가 먼저 만들어 둔 마쓰야마·다카마쓰·고베·삿포로·도쿄 맛집·183곳 지도 자료를 씨앗으로 넣음 |
| 가이드의 `profile` 항목 | 도시 얼굴 : 성격 한 줄(vibe) · 위치 설명(where) · 먹을/볼/할 것(known_for) · 이런 분께(best_for, 고정 목록 16개) · 비슷한 곳과 차이(vs, vs_key) · 검색 별칭(aliases) · 색(color) | 33곳 요약을 한 편집자가 한꺼번에 써서(34번째 미야코지마는 같은 규칙으로 따로 씀) 서로 겹치지 않게 하고, 점검 스크립트로 글자 수·목록·중복·긴 줄표를 확인. 위치 설명의 시간은 가이드의 공항 교통·시내 이동에 있는 값만 씀. 넣는 도구 `tools/apply_profiles.py`, 점검은 `validate_guide.py` |
| `data/icons.json` | 도시 그림 34장(평면 SVG, 한 장 2KB 안팎) | 이 프로젝트에서 직접 그림(외부 그림·로고·캐릭터 없음, 글자 없음). 조립 때 스크립트·외부 참조가 섞인 그림은 자동으로 뺀다 |
| `data/regions_geo.json` | 지역 9개 경계(홈의 지역별 색 지도) | Natural Earth 1:10m 현 경계(공개 자료)를 지역별로 합치고 단순화. `python3 -I travel/tools/build_regions_geo.py <ne_10m_admin_1_states_provinces.geojson>` (shapely 필요) |
| `data/art_regions.json` · `data/art_dishes.json` · `data/art_spots.json` · `data/art_hotels.json` | 지역 장면 그림 9장(가로 3:2) · 음식 그림 33종 · 볼거리 장면 21종 · 숙소 6종(정사각) | 이 프로젝트에서 직접 그림(평면 SVG). 식당마다 어떤 음식 그림을 쓸지는 cuisine 글로 자동 분류하고, '향토 요리'처럼 넓은 말이면 대표 메뉴(signature)를 앞에서부터 본다(`tools/dish_category.py`, 조립 때 dish 값으로 붙음) |

| `data/airport_names.json` | 일본 공항·도시 이름의 영어·일본어·중국어(간체·번체) 표기 | 손으로 작성 |
| `data/i18n/<언어>/<목적지>.json` | 가이드 본문 번역({"경로": "번역문"}) | `tools/i18n.py extract` 로 한국어 문장을 뽑고 → 언어별 번역 에이전트가 번역 → `tools/i18n.py check` 로 빠짐·한글 잔존 검사 → 조립 때 끼워 넣음. 번역이 없는 목적지는 한국어 원문이 그대로 들어가고 조립 요약에 표시됨 |
| `data/outline.json` | 한국·일본 해안선 | Natural Earth(공개 자료) 1:50m 을 단순화 |

| 상세 지도 그림(타일) | 일본 국토지리원 지리원 타일(연한 색 지도) → 안 되면 OpenStreetMap → 둘 다 안 되면 번호 약도 | 키 없이 공개된 서버. 순서와 주소는 `build_japan.py` 의 `TILES`. 정식 서비스 때는 계약한 지도 서버(키 포함)를 맨 위에 넣는다. CARTO 무료 지도는 2025년 이후 키 없이 부르면 'API KEY REQUIRED' 그림만 돌려주어 뺐다 |

## 자료 점검기

가이드 JSON 은 넣기 전에 반드시 점검기를 통과해야 합니다.

```
python3 -I travel/tools/validate_guide.py travel/data/guides/sapporo.json
```

빠진 항목, 모르는 분류값, 좌표가 범위 밖인 장소, 일정이 가리키는데 없는 장소·식당, 시각이 거꾸로 가는 일정, 식사 항목이 없는 날, 하루에 80km 넘게 건너뛰는 동선을 잡아냅니다. 조립 스크립트는 점검에 실패한 파일을 **빼고** 조립합니다(틀린 화면이 아니라 빈 목적지로 나타나게).

## 새 목적지·새 나라를 넣으려면

1. `data/guides/` 에 같은 모양의 JSON 을 하나 더 만든다(모양은 `tools/validate_guide.py` 와 기존 파일 참고).
2. 그 목적지의 공항이 `data/jp_airports.json` 에 있는지 본다. 없으면 공항·노선을 추가한다(출처 URL 필수).
3. `python3 travel/build_japan.py` 로 조립하고, 화면에서 확인한다.

다른 나라로 넓힐 때는 공항 파일과 해안선 파일을 나라별로 하나씩 더 두고, 조립 스크립트의 지도 투영 범위(`LON0`·`LAT1` 등)만 그 나라에 맞게 바꾸면 됩니다.

## 디자인

- 글꼴 : Pretendard(제목은 굵게, 본문은 보통). 오픈 폰트 라이선스(OFL)의 무료 글꼴이라 상업 이용·배포에 제한이 없습니다. 글꼴 파일을 못 받는 환경에서는 Noto Sans KR(OFL) → 아이폰 기본 고딕 순으로 대신 씁니다.
- 색 : 벚꽃 장미색을 중심으로 세이지(초록)·하늘·햇빛 노랑을 보조색으로 씁니다. 모든 그림(아이콘·도장·지도)은 직접 그린 SVG 라 저작권 문제가 없습니다.
- 아이폰 : 안전 영역(노치·홈바) 여백, 가로 스크롤 없음, 터치 영역 30px 이상, 글자 확대 없음을 헤드리스 브라우저(아이폰 13 화면)로 점검했습니다.
- 영문 큰 제목·숫자 : Instrument Serif(OFL 무료 글꼴, 한국어판에만 불러옴). 한글에는 쓰지 않습니다.
- 움직임(v1.5 포털) : 모든 화면 요소가 차례로 떠오르고(처음 보이는 것은 순서대로, 아래쪽은 스크롤할 때), 단추·카드는 눌리면 살짝 들어가며, 화면 넘김·시트는 탄성 있게 움직입니다. 위·아래 막대는 떠 있는 유리판입니다. 움직임은 모두 위치·투명도만 바꿔 휴대폰에서도 가볍고, 휴대폰 설정에서 '동작 줄이기'를 켜면 움직임 없이 바로 보입니다.

## 언어를 더하거나 번역을 고치려면

- 화면 글자는 `data/ui_strings.json` 의 해당 언어 항목을 고치고 다시 조립합니다.
- 가이드 본문은 `data/i18n/<언어>/<목적지>.json` 을 고칩니다. 경로는 `python3 -I travel/tools/i18n.py extract travel/data/guides/sapporo.json 임시.json` 으로 뽑은 파일과 같은 모양입니다.
- 새 언어를 더하려면 `ui_strings.json` 의 `langs` 목록과 글자 사전에 한 언어를 추가하고, `build_japan.py` 의 `FONTS` 에 그 언어의 글꼴(모두 OFL)을 지정합니다.

# 일본 직항 여행 플래너 (travel/)

출발 공항과 박 수만 고르면 **직항편 → 하루하루 동선 → 맛집 → 지도 → 숙소 → 예산 → 대체 동선·대체 여행지**까지 한 화면에서 보여 주는 여행 가이드 프로그램입니다. 일본을 첫 대상으로 만들었고, 같은 틀에 다른 나라 자료를 넣으면 그대로 늘어납니다.

- 다운로드용 한 파일 : **`dist/japan_travel_planner_ko_v1.3.html`** (한국어, 언어 버튼 없음. 컴퓨터 브라우저로 열면 지도까지 그대로 동작. 다시 만들 때 `python3 travel/build_japan.py --lang ko --no-lang-menu --out dist/japan_travel_planner_ko_v1.3.html`)
- 완성 파일 : **`travel/japan.html`** (한국어. 파일 하나. 아이폰 사파리·크롬·엣지 어디서나 열립니다. 지도 바탕 그림과 글꼴만 인터넷이 필요하고, 나머지는 인터넷 없이도 됩니다)
- 다른 언어 : `japan_en.html`(영어) · `japan_es.html`(스페인어) · `japan_zh.html`(중국어 간체) · `japan_yue.html`(중국어 광동어·번체) · `japan_ja.html`(일본어). 화면 오른쪽 위 지구본 버튼으로 오갑니다(보고 있던 목적지가 유지됨)
- 자료(데이터베이스) : `travel/data/` 아래 JSON 파일들
- 조립 : 저장소 루트에서 `python3 travel/build_japan.py`

## 화면 흐름

0. **도시 검색** : 맨 위 검색창. 한글·영어·일본어 이름, 초성(ㅅㅍㄹ → 삿포로), 치는 중인 글자(삿폴 → 삿포로), 받침 빠뜨린 오타(사포로), 흔한 표기(후쿠오까·교또), 공항 코드(FUK), 동네·섬(오타루·하카타·나하), 명소(후시미), 음식(라멘), 특징(온천·사슴)으로 찾는다. 결과마다 왜 걸렸는지(명소 · 후시미이나리 다이샤) 한 줄로 보여 준다
1. **출발 공항** 고르기 (인천·김포·김해·제주·대구·청주·무안 등 직항이 있는 공항만 뜸)
2. **며칠** 다녀올지 고르기 (2박3일 ~ 5박6일, 상관없음)
3. **직항 지도** : 한국·일본 지도 위에 **도시 핀과 이름**. 핀을 누르면 그 도시 그림·성격·위치·직항이 뜨고, **지역 버튼**(홋카이도 … 오키나와)을 누르면 그 지역으로 확대되며 아래 목록도 그 지역만 남는다. 가이드가 없는 공항(이바라키·도쿠시마·시모지시마 등)은 작은 점으로 남고, 누르면 가까운 여행지를 알려 준다
4. **여행지 카드** : 도시마다 **그림 한 장 · 성격 한 줄 · 일본 지도 위 위치 + 위치 설명 · 먹을 것/볼 것/할 것 · 이런 분께**가 붙는다. 지역(홋카이도 → 오키나와)별로 나열. 테마(온천·미식·아이동반 …)로 거르고, 비행시간순으로도 정렬
5. **여행지 화면** : 맨 위 **한눈에 보기**(위치 지도 · 어디쯤인지 · 먹을/볼/할 것 · 이런 분께 · 헷갈리는 비슷한 곳과 차이, 그 곳으로 바로 가기) → 직항편(항공사·시간·횟수·정기/계절/전세) → 공항에서 시내 가는 법 → 박 수 선택 → 추천 플랜과 **대체 플랜**(같은 박 수의 다른 동선) → 일차별 지도·타임라인(명소·식당 후보 2~4곳 중 고르기·숙소·이동) → 숙소 추천 · 예산 · 준비물 체크 · 플랜 B(비 오는 날, 아이와, 휴무일 때) · **대신 갈 만한 곳**(직항 정보와 함께) · 맛집 전체 · 명소 전체 · 참고 자료

고른 출발 공항·박 수·식당 선택·체크 표시는 그 기기 안에만 저장됩니다(서버 없음).

목적지마다 **특징·장점 해시태그**(예 : #공항에서 도심 40분, #우동 한 그릇 500엔)가 알록달록한 칩으로 카드와 상단에 붙습니다. 자료의 `highlights` 항목입니다.

## 자료는 어디서 왔나

| 파일 | 내용 | 만든 방법 |
|---|---|---|
| `data/jp_airports.json` | 일본 공항 전부와 한국 출발 직항 노선(항공사·비행시간·주 횟수·정기/계절/전세·출처 URL) | 일본 지역별 6명 + 한국 공항별 1명이 웹을 조사 → 공항마다 회의론자 1명이 노선 하나하나 반박 시도 → 한국 공항별 조사에만 있던 노선은 따로 검증. 정리 규칙은 `tools/merge_flights.py` 맨 위에 적어 둠 |
| `data/guides/<목적지>.json` | 목적지 하나의 명소·식당·숙소·공항 교통·박 수별 플랜·대체 동선·플랜 B·대체 여행지·예산·준비물 | 목적지마다 조사(장소) → 설계(동선) → 검증(회의론자가 폐업·휴무·좌표·동선 반박) → 정정의 4단계. 소유자가 먼저 만들어 둔 마쓰야마·다카마쓰·고베·삿포로·도쿄 맛집·183곳 지도 자료를 씨앗으로 넣음 |
| 가이드의 `profile` 항목 | 도시 얼굴 : 성격 한 줄(vibe) · 위치 설명(where) · 먹을/볼/할 것(known_for) · 이런 분께(best_for, 고정 목록 16개) · 비슷한 곳과 차이(vs, vs_key) · 검색 별칭(aliases) · 색(color) | 33곳 요약을 한 편집자가 한꺼번에 써서 서로 겹치지 않게 하고, 점검 스크립트로 글자 수·목록·중복·긴 줄표를 확인. 위치 설명의 시간은 가이드의 공항 교통·시내 이동에 있는 값만 씀. 넣는 도구 `tools/apply_profiles.py`, 점검은 `validate_guide.py` |
| `data/icons.json` | 도시 그림 33장(평면 SVG, 한 장 2KB 안팎) | 이 프로젝트에서 직접 그림(외부 그림·로고·캐릭터 없음, 글자 없음). 조립 때 스크립트·외부 참조가 섞인 그림은 자동으로 뺀다 |
| `data/kr_airports.json` | 한국 출발 공항 이름·좌표 | 손으로 작성 |
| `data/ui_strings.json` | 화면 글자 6개 언어 사전(버튼·제목·단위·태그 이름·항공사 이름) | 손으로 작성 |
| `data/airport_names.json` | 일본 공항·도시 이름의 영어·일본어·중국어(간체·번체) 표기 | 손으로 작성 |
| `data/i18n/<언어>/<목적지>.json` | 가이드 본문 번역({"경로": "번역문"}) | `tools/i18n.py extract` 로 한국어 문장을 뽑고 → 언어별 번역 에이전트가 번역 → `tools/i18n.py check` 로 빠짐·한글 잔존 검사 → 조립 때 끼워 넣음. 번역이 없는 목적지는 한국어 원문이 그대로 들어가고 조립 요약에 표시됨 |
| `data/outline.json` | 한국·일본 해안선 | Natural Earth(공개 자료) 1:50m 을 단순화 |
| `vendor/leaflet.*` | 지도 엔진 Leaflet 1.9.4 (BSD 라이선스) | npm 에서 받음 |
| 상세 지도 그림(타일) | 일본 국토지리원 지리원 타일(연한 색 지도) → 안 되면 OpenStreetMap → 둘 다 안 되면 번호 약도 | 키 없이 공개된 서버. 순서와 주소는 `build_japan.py` 의 `TILES`. 정식 서비스 때는 계약한 지도 서버(키 포함)를 맨 위에 넣는다. CARTO 무료 지도는 2025년 이후 키 없이 부르면 'API KEY REQUIRED' 그림만 돌려주어 뺐다 |

**숫자는 모두 "가정값"입니다.** 항공권·숙박비는 시기에 따라 두 배까지 차이가 나고, 영업시간·휴무일은 자주 바뀝니다. 화면 곳곳에 "확인 필요"가 붙은 값은 조사 때 근거를 못 찾은 것이니 예약 전에 꼭 확인하세요.

## 자료 점검기

가이드 JSON 은 넣기 전에 반드시 점검기를 통과해야 합니다.

```
python3 -I travel/tools/validate_guide.py travel/data/guides/sapporo.json
```

빠진 항목, 모르는 분류값, 좌표가 범위 밖인 장소, 일정이 가리키는데 없는 장소·식당, 시각이 거꾸로 가는 일정, 식사 항목이 없는 날, 하루에 80km 넘게 건너뛰는 동선을 잡아냅니다. 조립 스크립트는 점검에 실패한 파일을 **빼고** 조립합니다(틀린 화면이 아니라 빈 목적지로 나타나게).

## 새 목적지·새 나라를 넣으려면

1. `data/guides/` 에 같은 모양의 JSON 을 하나 더 만든다(모양은 `tools/validate_guide.py` 와 기존 파일 참고).
2. 그 목적지의 공항이 `data/jp_airports.json` 에 있는지 본다. 없으면 공항·노선을 추가한다(출처 URL 필수).
3. `python3 travel/build_japan.py` 로 조립하고, 화면에서 확인한다.

다른 나라로 넓힐 때는 공항 파일과 해안선 파일을 나라별로 하나씩 더 두고, 조립 스크립트의 지도 투영 범위(`LON0`·`LAT1` 등)만 그 나라에 맞게 바꾸면 됩니다.

## 디자인

- 글꼴 : Pretendard(제목은 굵게, 본문은 보통). 오픈 폰트 라이선스(OFL)의 무료 글꼴이라 상업 이용·배포에 제한이 없습니다. 글꼴 파일을 못 받는 환경에서는 Noto Sans KR(OFL) → 아이폰 기본 고딕 순으로 대신 씁니다.
- 색 : 벚꽃 장미색을 중심으로 세이지(초록)·하늘·햇빛 노랑을 보조색으로 씁니다. 모든 그림(아이콘·도장·지도)은 직접 그린 SVG 라 저작권 문제가 없습니다.
- 아이폰 : 안전 영역(노치·홈바) 여백, 가로 스크롤 없음, 터치 영역 30px 이상, 글자 확대 없음을 헤드리스 브라우저(아이폰 13 화면)로 점검했습니다.

## 언어를 더하거나 번역을 고치려면

- 화면 글자는 `data/ui_strings.json` 의 해당 언어 항목을 고치고 다시 조립합니다.
- 가이드 본문은 `data/i18n/<언어>/<목적지>.json` 을 고칩니다. 경로는 `python3 -I travel/tools/i18n.py extract travel/data/guides/sapporo.json 임시.json` 으로 뽑은 파일과 같은 모양입니다.
- 새 언어를 더하려면 `ui_strings.json` 의 `langs` 목록과 글자 사전에 한 언어를 추가하고, `build_japan.py` 의 `FONTS` 에 그 언어의 글꼴(모두 OFL)을 지정합니다.

## 내용 점검기

형식 점검기(`validate_guide.py`)와 따로, 일정의 '내용'을 점검하는 도구가 있습니다.

```
python3 -I travel/tools/lint_guides.py            # 33곳 전체
python3 -I travel/tools/lint_guides.py travel/data/guides/tokyo.json   # 한 곳만
```

식사 시각이 첫 후보 식당의 영업시간 밖인 일정, 마감 뒤 시설 방문, 이동이 끝나기 전에 시작하는 다음 일정, 같은 날 같은 곳 두 번 방문, 숙소 가격 빈칸, 중심에서 150km 넘게 떨어진 좌표, 없는 목적지를 가리키는 '대신 갈 만한 곳'을 찾습니다. 숙박하는 온천의 밤 목욕, 테마파크 개장 전 줄서기처럼 일부러 그렇게 짠 일정은 주의로 남을 수 있습니다(지금 10건, 모두 일부러 둔 것).

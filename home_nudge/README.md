# MeAI 홈 넛지 플레이 v5 (고도화 목업 + 개발 패키지) · v5.1 행운 존

MeAI 홈에서 영업가족이 **매일 홈을 열고(출석) · 배우고(퀴즈 · 화법) · 영업하게(추천 고객 · 맞춤대화)** 만드는 넛지 장치 모음이다.
기획안 v3(2026-10-06, 28장)와 목업 v3/v4 를 이어받아 더 풍성하고 세련되게 다듬었고, 개발자가 그대로 만들 수 있게 설계도 · API · DB · 소스 · 테스트까지 묶었다.

- 고도화 목업 : `dist/meai_home_nudge_v5.html` (한 파일 · 약 7.7MB · 인터넷 필요 없음 · 크롬/엣지로 열기 · 왼쪽 아래 「데모 메뉴」 · 막대 끝 「행운 존」)
- 개발 패키지 : `dist/meai_home_nudge_v5_package.zip` (IT 담당이 받는 것 · 안의 `README_FIRST.md` 부터)
- 설계도 : `home_nudge/docs/BLUEPRINT.md` (보기 좋은 판 `.html` · `.pdf`)

## v5.1 에서 더한 것 : 행운 존 (2026-10-29)

막대 끝 「더보기 ⋯」 자리를 **「행운 존」** 칸으로 바꿨다(넛지 설정은 행운 존 · 지갑 카드 아래로). 재미 장치의 끝은 언제나 「오늘 누구에게 연락할까」 또는 「오늘 무엇을 배울까」다.

| 장치 | 하는 일 |
|---|---|
| CRM 룰렛 | 8칸 돌림판이 고객 활동(생일 축하 · 상령일 · 갱신 · 보장 점검 · 건강검진 · 감사 인사)을 고르고, 어울리는 내 고객 3명과 안부 문구를 붙여 준다. 「연락했어요」 → XP. 보너스 칸은 응모권 +1 · 나만의 피버 30분 |
| 추천 고객 슬롯 | 릴 3개(생일 · 상령일 · 갱신 · 보장 공백 · 동의 필요)로 오늘 챙길 고객 3명. 같은 사유 3명이면 트리플(응모권 +1) |
| OX 스피드 챌린지 | 5문제 · 10초 · 콤보 · 최고 기록 · 만점이면 응모권 +1. 문제 은행 39문항 : **오늘의 약관 15**(특약검색기 약관 원문에서 확인한 문장) · 메디컬 9 · 보험 제도 6 · 준법 6 · MeAI 3 |
| 오늘의 타로 | 카드 3장 중 하나 → 1909 원판 그림 · 풀이 · 고객에게 보낼 한마디 |
| 스크래치 복권 | 일일 미션 · 올클리어 때 1장. 은박을 긁으면 XP · 응모권 · 보호권 · 피버(꽝 없음) |
| 오늘의 운세 | 「오늘의 운세(사주 + 타로)」 엔진 원본 그대로 : 점수 · 재물/대화/일/컨디션 · 행운 색 · **오늘의 대화 한마디**. 전체 운세는 홈 위 덮개 안에서 연다. 생년월일은 이 기기에만 |
| 영업 빙고 | 이번 주 행동 9칸이 저절로 채워지고 줄마다 응모권 |
| 피버 타임 | 영업일 14~15시 영업 행동 XP ×2 (+ 나만의 피버) · 막대 칸이 불꽃으로 바뀜 |

- 확률은 모두 게임 화면에 숫자로 공개하고, 운으로 받는 응모권은 하루 3장까지(넘치면 XP). 「연락했어요」는 화면 신고라 XP 만 준다.
- 오늘의 퀴즈에 등록 문항이 없는 날은 OX 문제 은행에서 갈래를 번갈아 낸다.

## 다시 만드는 순서

```
python3 home_nudge/build.py                       # 목업 (dist/meai_home_nudge_v5.html)
node home_nudge/tests/rules.test.js               # 규칙 112건
python3 home_nudge/tools/check_quiz_terms.py      # OX 약관 문항 ↔ 특약검색기 약관 원문 · 분류표 글자 대조
node home_nudge/tools/check_mockup.js             # 목업 흐름 · 첫 화면 · 휴대폰 (캡처 : 두 번째 인자로 폴더)
node home_nudge/tools/check_sandbox.js            # 연습 화면 · 엄격한 CSP
python3 home_nudge/tools/check_contract.py        # 모의 서버 응답 ↔ openapi.yaml
node home_nudge/tools/check_a11y.js <axe-core 폴더>   # 접근성 (npm pack axe-core@4.10.2)
node home_nudge/tools/shoot_docs.js               # 설계도 그림 (docs/img) 다시 찍기
node home_nudge/tools/render_doc.js home_nudge/docs/BLUEPRINT.md <marked 폴더> <mermaid 폴더>   # 설계도 .html · .pdf
python3 home_nudge/build.py --package             # + 개발 패키지 zip
```

- 규칙(보상 숫자 말고 판정 방식)을 일부러 바꿨으면 `node home_nudge/tests/make_vectors.js` 로 벡터를 다시 만들고, 무엇이 왜 바뀌었는지 아래 변경 기록에 적는다.
- 화법 데이터를 다시 뽑을 때 : `python3 home_nudge/tools/import_talks.py <v3 목업.html>` (이름 가림이 기본).
- 설계도 그림 도구 : `npm pack marked@12.0.2 mermaid@10.9.1` → 압축을 풀어 두 폴더를 넘긴다.

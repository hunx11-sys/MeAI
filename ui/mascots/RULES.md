# 걱정인형 사용 규칙 (요약)

출처 : `메리츠_걱정인형_리디자인가이드_최종_0827.pdf` (2021 개선 디자인 가이드북) 3쪽 「메뉴얼 관리 규정」 · 6~29쪽 캐릭터 색상 · 30쪽 흑백 버전.

## 지켜야 할 것 (가이드 3쪽 원문 요약)
1. 가이드는 반드시 지킨다. 어떤 부분도 **임의로 해석하거나 바꿔 쓰지 않는다.** 궁금하면 메리츠화재 **홍보파트와 협의**한다.
2. 크기를 키우거나 줄일 때는 **가로세로 비율을 그대로(정비례)** 둔다 — 찌그러뜨리거나 늘이지 않는다.
3. 응용 이미지(행동·상황·계절)는 **그 테마에 속한 캐릭터·이미지끼리만** 함께 쓴다.
4. 캐릭터 모양이나 **색을 고쳐야 할 때는 반드시 홍보파트와 협의**한다 — 임의 색 바꾸기 금지.
5. 따로 정해진 **여백(clear space)·금지 예시 쪽은 가이드에 없다.** (화면에서는 그림 둘레를 넉넉히 비우는 정도로 운영 — 사내 판단)

## 이번 사이트 작업 메모
- 사이트의 도구별 강조색(메리 #C73D1C 등)은 **화면 강조색**이지 캐릭터 색이 아니다. 캐릭터 그림 자체의 색은 바꾸지 않는다.
- 2D 스타일(이 폴더)과 3D 렌더를 한 화면에 섞지 않는 편이 좋다(가이드 3번 「같은 테마끼리」 취지).
- 「동물나라 에디션」(메리츠 파트너스) 그림은 다른 테마라 쓰지 않았다.
- 크리스마스·한복·토끼옷 등 계절 그림은 고르지 않았다.

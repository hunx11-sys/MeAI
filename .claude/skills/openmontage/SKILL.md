# 오픈몽타주로 영상 만들기

오픈몽타주는 이 저장소에 들어 있지 않다(남의 프로그램 · AGPL-3.0). 세션마다 공식 저장소에서 받아 쓴다.
이 저장소에는 우리 쪽 설정만 있다 — `video/`(설치 스크립트 · 환경값 · 배경음 만들기 · 안내 `video/README.md`).

## 1. 준비 (세션마다 한 번 · 40초~1분)

```bash
bash video/openmontage_setup.sh          # 받기 + 설치 + 한글 글꼴 + 배경음 + 「지금 되는 기능」 요약
bash video/openmontage_setup.sh --smoke  # 의심스러우면 : 한국어 시험 영상까지 만들어 본다(video/out/)
```

몇 번을 돌려도 된다(된 단계는 건너뛴다). 실패하면 화면에 나온 사유를 소유자에게 그대로 알린다.

## 2. 명령을 칠 때마다 환경값부터

셸 상태가 다음 명령으로 넘어가지 않으므로 **영상 관련 명령은 매번** 이렇게 시작한다.

```bash
source /home/user/MeAI/video/env.sh && cd "$OM" && <명령>
```

`env.sh` 가 하는 일 : 오픈몽타주 파이썬을 앞에 두고, 캡처 전용 브라우저를 지정하고(없으면 둘째 엔진이 훨씬 느리다 · 4초 영상 85초 → 6초), 사용 통계 전송을 끄고, 배경음 보관함 · 완성본 폴더(`$MEAI_VIDEO_OUT`) 위치를 알려 준다.

## 3. 오픈몽타주의 규칙을 따른다

`$OM/AGENT_GUIDE.md` 를 **처음부터 끝까지 읽고** 그대로 한다. 핵심만 적으면 :

- 영상 요청은 반드시 파이프라인(`pipeline_defs/*.yaml`)을 골라 단계별로 간다. 단계마다 `skills/pipelines/<파이프라인>/<단계>-director.md` 를 먼저 읽는다. 도구를 즉흥 스크립트로 바로 부르지 않는다.
- 시작 전에 「지금 되는 기능」을 확인하고(`registry.provider_menu_summary()`), 소유자에게 쉬운 말로 알려 준다.
- 기획안 · 대본 · 장면 구성 · 만든 재료는 **소유자 승인을 받고** 다음으로 간다(승인 대기에서 차례를 끝낸다). 돈이 드는 생성은 도구 · 금액을 먼저 말한다.
- 화면 합성 엔진 두 가지(Remotion · HyperFrames)가 다 되면 둘 다 보여 주고 고르게 한다. 아래 「라이선스」를 꼭 같이 말한다.
- 요청이 막연하면(「영상 하나 만들어줘」) `skills/meta/onboarding.md`, 참고 영상 주소를 주면 `skills/meta/video-reference-analyst.md` 부터.

소유자는 프로그래밍을 하지 않는다. 선택지 · 진행 상황은 전문용어 없이 한국어로 말한다.

## 4. 이 작업 환경에서 되는 것 · 막힌 것 (2026-11-21 확인)

| | 상태 |
|---|---|
| 화면 합성 3종(FFmpeg · Remotion · HyperFrames) | 된다 · 한글은 프리텐다드로 나온다 |
| 자막 · 편집 · 합치기 · 색 보정 · 화면 녹화 · 캐릭터 애니메이션(SVG) | 도구는 설치돼 「가능」으로 나온다. 아직 실제로 돌려 보지는 않았다 — 처음 쓸 때 짧게 시험하고 결과를 `video/README.md` 에 적는다 |
| 배경음 | 보관함 3곡(`meai_calm` · `meai_bright` · `meai_focus` · 직접 합성한 간단한 곡) + 소유자가 `video/music/` 에 넣은 파일 |
| **한국어 내레이션** | **된다**(2026-11-22). Supertonic 3 + sherpa-onnx · 무료 · 키 없음 · 로컬 합성. 도구 `supertonic_tts`(provider `supertonic`) — 아래 「한국어 내레이션」 |
| 인터넷 무료 재료(Archive.org · NASA · 위키미디어 실사 영상 · Pixabay 음악 · Pexels) | **안 된다.** 주소가 허용 목록에 없다. 도구 목록에는 「가능」으로 보여도 실제 요청은 거부된다 |
| AI 그림 · AI 영상 · 아바타 | 키가 없어 안 된다(전부 선택 사항) |
| 진행 상황판(Backlot) | 클라우드 세션에는 띄울 화면이 없다. `python -m backlot open` 은 건너뛰고 진행 상황을 글로 알린다 |

막힌 것을 만나면 **돌아가는 길을 몰래 찾지 않는다.** 무엇이 막혔고 어떤 선택지가 있는지 말한다(`video/README.md` 「막혀 있는 것을 풀려면」).

**주소 허용 승인 창은 모바일 앱에서 처리되지 않는다(소유자 2026-11-22 : 「모바일에서는 안 되고 PC 에서만 된다」고 나온다).** 2026-11-21(주소 7개) · 11-22(주소 2개) 요청이 「거절」로 돌아온 것은 소유자가 거절한 것이 아니라 모바일이라 처리되지 않은 것이다. 그래서 주소 허용이 필요하면 **요청을 띄우기 전에 「지금 PC 인지」 먼저 묻는다** — 모바일이면 띄우지 않고, PC 에서 「주소 허용 다시 해줘」라고 하면 그때 띄운다고 안내한다. API 키는 채팅에 받지 않는다(보안 입력 창 — 이것도 모바일에서 안 뜰 수 있다).

## 4-1. 한국어 내레이션

- 음성 선택기로 부른다 : `tts_selector` 에 `{"text": ..., "preferred_provider": "supertonic", "voice": 0~9, "speed": 1.0, "language_code": "ko", "output_path": ..., "srt_path": ...}`. 결과의 `segments`(문장 · 시작 · 끝 초)로 장면 길이와 자막을 맞춘다.
- 목소리 : 0~4 여성, 5~9 남성(음높이로 추정한 구분). 소유자가 고른 번호가 있으면 그것을 쓴다(없으면 견본 `python video/korean_voice.py voices -o <폴더>` 를 만들어 들려주고 고르게 한다).
- **클로드는 소리를 듣지 못한다.** 만든 내레이션은 길이 · 소리 크기만 확인할 수 있다. 발음(숫자 · 영어 · 상품명 · 약어)은 소유자가 들어야 안다 — 대본 확인 단계에서 짧은 견본을 먼저 들려준다. 어색하다고 하면 대본에서 한글로 풀어 쓴다(「35,000원」 → 「삼만 오천 원」, 「MeAI」 → 소유자가 부르는 대로). 소유자가 알려 준 읽는 법은 `video/README.md` 에 적어 다음에도 쓴다.
- 화면 자막의 낱말 시간은 `meai_korean_voice.word_captions(segments)` — 문장 시간은 정확하고 낱말 시간은 어림값이다. 낱말 강조가 어긋나 보이면 문장 단위 자막으로 바꾼다.
- 감정 연기 · 특정인 목소리 흉내는 안 된다. 고객에게 나가는 영상에는 「AI 음성」 표기를 권한다.
- 목소리 모델은 npm 재포장본에서 받아 지문값(SHA256)이 맞을 때만 쓴다(`video/korean_voice.py` 맨 위). 「다릅니다」 로 멈추면 **지문값을 고쳐서 넘기지 말고** 소유자에게 알린다.

## 4-2. 실제 제작에서 배운 것 (2026-11-22 첫 제작 · `video/README.md` 변경 기록)

- 대본 길이 : 1.1배 빠르기에서 글자(띄어쓰기 포함) 약 7.7자 = 1초. 요청 길이 × 7.7 을 넘지 않게 쓰고, 화면에 글자로 남는 세부(날짜 범위 · 각주 · 모든 금액)는 말에서 뺀다.
- 숫자는 읽기용 글에서 한글로 풀어 쓰고(이천십삼 년 · 오십 퍼센트 · 엠알아이), 화면 자막은 숫자 그대로 둔다 — 문장마다 [화면용, 읽기용] 짝으로 대본을 쓴다.
- 직접 작성한 HyperFrames 화면은 `hyperframes_compose` 의 `render_existing` 으로 렌더한다(품질 점검이 먼저 돈다). 글꼴은 `@font-face` 로 작업 폴더 안의 프리텐다드를 가리켜야 점검을 통과한다. GSAP 는 npm 에서 받아 작업 폴더에 넣는다(인터넷 주소 금지).
- 품질 점검은 흰 글자 대비 4.5 : 1 미만이면 멈춘다 — 메리츠 빨강 띠 위 흰 글자는 #C62F29 정도로 진하게.
- 렌더 시간 : 5분 영상 약 7분 30초(4코어). 렌더 전에 `npx hyperframes snapshot --at <장면마다 끝 무렵>` 으로 화면을 먼저 확인하고 고친다.
- 캐릭터 그림을 원본 PDF 에서 잘라 쓸 때는 장면 바탕을 원본 바탕색(#FBEFEF)과 같게 하고, 가장자리만 살짝 흐리게(mask) 한다. 밝은 그라데이션을 바탕에 두면 그림 테두리가 상자처럼 보인다.

## 5. 라이선스 (기획 단계에서 말한다)

- **HyperFrames** : Apache-2.0. 회사 업무용 영상에 제한이 없다 → **회사에서 쓸 영상은 이쪽을 권한다.** 속도도 빠르다.
- **Remotion** : 특수 라이선스. 패키지 설명에 「경우에 따라 회사 라이선스를 사야 한다」고 적혀 있다(개인 · 아주 작은 조직은 무료로 알려져 있으나 정확한 조건은 remotion.dev/license 에서 확인 — 이 환경에서는 원문을 열어 보지 못했다). 메리츠화재 업무용으로 쓰려면 소유자가 조건을 확인해야 한다. 개인 연습 · 시험용으로만 쓰거나, 확인 전에는 HyperFrames · FFmpeg 로 간다.
- **오픈몽타주** : AGPL-3.0. 받아서 쓰는 것은 자유다. 그 코드를 이 저장소에 복사해 넣지 않는다.
- **프리텐다드 글꼴** : SIL OFL 1.1(영상에 자유롭게 사용).
- **Supertonic 3 목소리 모델** : OpenRAIL-M(용도 제한이 붙은 조건부 라이선스 — 사칭 · 속임 등 금지). **sherpa-onnx** : Apache-2.0.

## 6. MeAI 규칙을 영상에도 그대로

- 디자인은 `design/` 의 회사 문서를 따른다(`design-md` 스킬) — MeAI 것은 `design/DESIGN-MeAI.md`. 글꼴은 프리텐다드.
- 숫자 · 통계는 출처를 붙이거나 「가정값」으로 표기한다. 보험 금액 · 질병코드는 만들어 내지 않는다(약관 · 특약 마스터에서만).
- 설계사명 · 고유번호 · 고객 정보가 화면에 나오지 않게 한다. 사내 화면 캡처는 가린다.
- 파일명은 ASCII(예 `meai_flywheel_short_v1.mp4`).

## 7. 끝낼 때

1. 완성본을 `$MEAI_VIDEO_OUT`(= `video/out/`)에 복사한다. 오픈몽타주 폴더는 소유자가 앱에서 열 수 없다.
2. ffprobe 로 길이 · 해상도 · 소리 유무를 확인하고, 장면 몇 장을 뽑아 직접 눈으로 본다(한글 깨짐 · 잘림 · 빈 화면).
3. 파일을 소유자에게 보낸다(SendUserFile). 컨테이너는 임시라 세션이 끝나면 사라진다 — **보내지 않으면 남지 않는다.**
4. `video/out/` 과 오픈몽타주의 `projects/` 는 저장소에 올리지 않는다. 다시 쓸 재료(대본 · 장면 구성 json)를 남겨야 하면 소유자에게 물어 `video/projects/<이름>/` 에 글자 파일만 둔다.

## 고칠 때

- 오픈몽타주 판을 올리려면 `video/openmontage_setup.sh` 의 `PINNED` 를 바꾸고 `--smoke` 로 확인한 뒤 `video/README.md` 변경 기록에 적는다.
- 이 환경의 되는 것 · 막힌 것이 바뀌면 위 4번 표와 `video/README.md` 를 같이 고친다.

## 이번 판에서 바뀐 것 (2026.09.29)

1. **새 목업(v2) 반영** — 화면을 모두 다시 찍어 옛 목업과 한 장씩 비교했습니다. 바뀐 것은 두 가지뿐이었습니다.
   - 대문·고객찾기·게시판 오른쪽 위 **[글씨 확대] ON/OFF 스위치** (기본 ON = 작은 글씨 한 단계 크게, 이 PC에 기억) → PART 2에 새 장
   - 고객찾기 **'부족' 그룹 태그 7개가 그룹마다 다른 색** (암 빨강·뇌 노랑·심 분홍·표적항암 갈색·종수술비 올리브·지원일당 초록·치아 회색) → PART 4에 새 장
2. **영업포탈 MeAI 진입점 6군데 (10/2부터)** — PART 2 맨 앞 2장. 기존 ①②⑥은 사용권한 필요, 신설 ③롤링배너 ④CRM 리스트 ⑤떠 있는 버튼은 누구나(적용 시점은 IT 일정에 따라 달라질 수 있음).
3. **글 줄이기** — 장마다 메시지 하나만 남기고 글자 수를 약 절반으로 줄였으며, 줄인 만큼 글자와 캡처를 키웠습니다.
4. **검수 후 바로잡은 것** — 게시판 글 상세 캡처가 절반 검게 잘려 있던 것, 카카오톡 캡처의 이름 가림이 좁아 이름 앞 글자가 보이던 것, "2.3배"(질문 1개 대비 **3개 이상**)를 "하나만 더"로 쓴 것, 출처가 빠진 숫자.

## 이 책에서 "가정"으로 둔 것

- 화면 캡처는 **개발 목업(`prototype/index_260929_v2.html`)** 을 찍은 것이라 고객 이름·숫자는 모두 **예시 데이터**입니다.
- 용어 설명·모드 변경처럼 개발 중인 기능에는 **"개발 진행 중 · 오픈 시 세부 변경 가능"** 표시를 붙였습니다.
- 오늘의 추천 고객은 게시판 공지대로 **CRM 데이터 반입이 끝나는 2차 오픈부터** 보이는 것으로 썼습니다.
- 통계 숫자의 출처는 데이터분석팀 「MeAI 사용 실태 분석」·「MeAI 효과 분석」(2026.08), 7%·2% 미만은 세일즈혁신TF CRM 대문 고도화 제안(2026.09)이며 각 장에 적었습니다.
- 영업포탈 진입점 그림은 소유자가 준 기획 화면(10/2 반영분)이고, 요약 리포트·모바일 장의 휴대폰 캡처는 v3(2026.06) 실제 화면입니다. 카카오톡 캡처의 이름은 가렸습니다.

## 다시 만들려면

```
cd guidebook_v4/build
npm install                     # 처음 한 번 (pptxgenjs, sharp, playwright)
node deck.js MeAI_guidebook_v4_CRM_2026.10.pptx   # 편집용 pptx
ONLY=p4 node deck.js p4.pptx     # 한 파트만 빠르게 확인
bash finalize.sh                 # pptx + 통이미지판 + PDF 한 번에 (LibreOffice·poppler 필요)
```

문구를 고칠 때는 `build/parts/` 의 해당 파트 파일에서 한글 문장을 찾아 바꾸고 다시 만들면 됩니다.
사외로 나가는 캡처에는 개인정보(설계사명·고객명)가 없는지 확인합니다.

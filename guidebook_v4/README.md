## 영업가족판으로 바꾼 것 (2026.09.30)

소유자 요청: "관리자용이 아니라 영업가족이 직접 보는 내용으로, 본인 고객을 MeAI 홈으로 이렇게 터치해 보라는 톤으로", "'2차 오픈'은 빼", "홈에서 부담보 해제 데이터는 쓸 수 없으니 그 예시는 빼고 상령일 임박 같은 예시로", "가이드북도 방송판과 같은 느낌으로".

1. **독자를 영업가족으로.** 표지·읽는 법·목차에서 '관리자 편'을 뺐고, **관리자 편(옛 PART 8, 7장)** 을 지우고 그 자리에 **PART 8 「MeAI 활용 방법 · 이렇게 물어보세요」(6장)** 를 새로 넣었습니다(질문은 고르는 것 · 직접 물을 땐 "누구에게 + 무엇을" · 고객에게 할 말 초안 · 이렇게는 묻지 마세요 · 카드별 첫 말·첫 질문). 관리자 편의 숫자(4,912명·3.9배·2,156명 등)는 쓰지 않습니다. 옛 관리자 편은 git 기록(커밋 4b00c21)에 남아 있습니다.
2. **'대문' → 'MeAI 홈'.** 책 제목·꼬리말·본문 모두 바꿨습니다. 출처 문서 제목 「MeAI CRM 대문 고도화 제안」과 화면 캡처 속 목업 글자(게시판 공지 제목 등)만 그대로입니다.
3. **부담보 예시를 모두 뺐습니다.** 목업 MeAI 홈은 처음 열면 추천 세트 1(첫 카드 최수영 · "부담보 해제가 5일 남았습니다")이 떠서, 그 화면을 쓴 캡처를 모두 **추천 세트 3(김민수·정재민·서은아)** 과 **세트 2(박준호)** 로 다시 찍었습니다.
   - 대표 예시: **김민수**(상령일 2주 · 암진단비 1천만원 · 사전조회동의 필요 · AI 추천 고객)
   - "클릭 두 번" 흐름: **서은아**(보상 후 후속 상담 · 동의 D-7이라 바로 맞춤대화)
   - PART 7 시나리오 1: 부담보 해제 D-5 → **박준호 · 자동차보험 만기 D-9, 운전자 보장까지**
   - 표·목록에서도 '부담보'를 뺐습니다(무엇을 보고 골랐나, 태그 설명 '만기·해제·상령일' → '만기·동의 만료·상령일'). 고객찾기 검색창의 추천 속성 칩 '부담보'는 캡처에서 지웠습니다.
4. **'2차 오픈'을 뺐습니다.** "※ 추천 고객은 2차 오픈부터" 줄을 지웠고, 게시판 공지 캡처도 그 문장을 뺀 화면으로 다시 찍었습니다. FAQ는 "오늘의 추천 고객은 CRM 데이터 반입이 끝난 뒤부터 보여요(게시판 공지)"로만 답합니다.
5. **'아침 3분 루틴' → '매일 아침 루틴'.** 잰 시간이 아니어서 '3분'을 뺐습니다.
6. **방송판과 같은 흐름.** 네 걸음 **찾기 → 고르기 → 묻기 → 터치하기** 와 "카드 문장은 고객에게 첫 말, 추천 질문은 MeAI에게 첫 질문"을 PART 0·1·7·8·9에 맞췄고, PART 6 맨 앞에 **"MeAI 홈에서 누르기만 하면 MeAI가 열려요"(대화를 여는 세 길)** 와 **"일반대화 화면"** 두 장을 새로 넣었습니다. 맺음말에 MeAI 홈을 만든 **AI추진파트 문현우님·이경복님** 감사 인사를 넣었습니다.
7. **가린 것.** 해지·전환·정리 권유로 읽힐 수 있는 목업 글자(답 아래 질문 버튼 2·3번 등. 정재민 카드는 2차 다듬기 때 예시 문장으로 채움)와 목업의 업데이트 날짜, 영업포탈 그림의 직함·수수료 칸은 방송판과 똑같이 가렸습니다. 맞춤대화 캡처 안내문의 목업 고정 예시 이름(정메리)은 왼쪽 담당 고객 이름과 맞춰 찍었습니다.

## 영업가족 방송판 (2026.09.30)

```
cd guidebook_v4/build
npm install                     # 처음 한 번 (pptxgenjs, sharp, playwright)
```

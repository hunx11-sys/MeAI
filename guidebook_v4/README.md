## 이번 판에서 바뀐 것 (2026.09.29)

1. **새 목업(v2) 반영** — 화면을 모두 다시 찍어 옛 목업과 한 장씩 비교했습니다. 바뀐 것은 두 가지뿐이었습니다.
   - 대문·고객찾기·게시판 오른쪽 위 **[글씨 확대] ON/OFF 스위치** (기본 ON = 작은 글씨 한 단계 크게, 이 PC에 기억) → PART 2에 새 장
   - 고객찾기 **'부족' 그룹 태그 7개가 그룹마다 다른 색** (암 빨강·뇌 노랑·심 분홍·표적항암 갈색·종수술비 올리브·지원일당 초록·치아 회색) → PART 4에 새 장
2. **영업포탈 MeAI 진입점 6군데 (10/2부터)** — PART 2 맨 앞 2장. 기존 ①②⑥은 사용권한 필요, 신설 ③롤링배너 ④CRM 리스트 ⑤떠 있는 버튼은 누구나(적용 시점은 IT 일정에 따라 달라질 수 있음).
3. **글 줄이기** — 장마다 메시지 하나만 남기고 글자 수를 약 절반으로 줄였으며, 줄인 만큼 글자와 캡처를 키웠습니다.
4. **검수 후 바로잡은 것** — 게시판 글 상세 캡처가 절반 검게 잘려 있던 것, 카카오톡 캡처의 이름 가림이 좁아 이름 앞 글자가 보이던 것(방송판 작업 때 가림 왼쪽 끝을 조금 옮겨 앞 글자 '요청하신'이 잘리지 않게 다시 맞춤), "2.3배"(질문 1개 대비 **3개 이상**)를 "하나만 더"로 쓴 것, 출처가 빠진 숫자.

## 영업가족 방송판 (2026.09.30)

영업가족이 직접 보는 사내 방송용입니다. "내 고객을 MeAI 홈에서 찾아, MeAI에게 묻고, 이렇게 터치해 보세요"라는 톤으로, 가이드북 v4와 예전 영업가족편(질문하는 법)을 묶었습니다. 방송 길이는 정해 두지 않았고, 큐시트 기준 예상 약 36분(개발자 코너는 유동)입니다.

| 순서 | 장 | 내용 |
|---|---|---|
| 여는 말 · 왜 MeAI 홈인가 | 1–3 | 표지, 오늘의 순서, 연락 못 한 내 고객(7%·2%)과 MeAI를 쓴 경우 체결전환율 |
| **만든 분께 듣기** | 4–5 | AI추진파트 문현우님·이경복님 초대. MeAI 홈이 움직이는 방식(고객 데이터 → 매일 밤 계산 → 오늘의 추천 고객 9명·그룹 → 이유 한 문장 → 맞춤대화) |
| 1 찾기 | 6–8 | 영업포탈 진입점, MeAI 홈 한 화면, 추천 카드 한 장(김민수 고객) |
| 2 고르기 | 9–11 | 고객찾기 세 칸, 그룹 설명 = 상담 화법, 동의 상태 |
| **3 묻기 (MeAI 활용 방법)** | 12–17 | 질문은 고르는 것(질문 예시·추천 질문·꼬리질문), "보장분석 해줘", 답 읽는 순서, 직접 묻는 법(누구에게 + 무엇을), 고객에게 할 말 초안, 이렇게는 묻지 마세요 |
| 4 터치하기 | 18–22 | 김민수 고객 시연(상령일 2주 전 · 동의부터), 고객에게 첫 말·MeAI에게 첫 질문, 요약 리포트, 첫 5일, 마무리 |
| 진행 큐시트 (송출 제외) | 23 | 장별 예상 시작 시각·진행 메모. 편집용 pptx에만 숨김 장으로 들어 있고, PDF·통이미지판은 22장 |

- **부담보 예시는 쓰지 않습니다.** MeAI 홈에서 부담보 해제 데이터는 쓸 수 없어(소유자 확인 2026.09.30), 예시 고객을 가이드북 v4 시나리오 3의 김민수 고객(상령일 2주 · 암진단비 1천만원 · 사전조회동의 필요)으로 바꿨습니다. MeAI 홈 캡처는 추천 세트 3(김민수·정재민·서은아)을 띄워 새로 찍었습니다.
- **생방송 시연 주의**: 목업 MeAI 홈은 처음 열면 추천 세트 1(첫 카드가 부담보 예시)이 뜹니다. 방송 전에 세트 3을 띄워 두고, 세트 1·2와 검색창의 추천 조건 칩은 내보내지 않습니다(18장 진행 메모).
- **개발자 코너(4·5장)**: 흐름 그림은 확정 목업의 안내 문구(게시판 예시 글·범례·고객찾기 안내)로 확인되는 것만 그렸습니다. 선정 기준·데이터 원천·개발 방식은 두 분이 직접 설명하도록 비워 두었고, 5장 발표자 노트에 '방송 전 두 분과 확인할 것 7가지'와 '말하지 않을 것'을 적었습니다.
- 영업포탈 그림의 직함·접속 정보·수수료 칸, 목업의 업데이트 날짜는 가렸습니다. 해지·전환·정리 권유로 읽힐 수 있는 글자(추천 세트 3 정재민 카드의 '중복 보장 정리' 문장, 답 아래 질문 버튼 2·3번, 답변의 '겹치는 담보는 정리해요' 줄, 리포트 화면의 '해지/유지 판단' 질문)도 지웠습니다. 생방송에서 목업을 띄울 때도 이 부분이 나가지 않게 각 장 진행 메모에 적었습니다.
- 다시 만들 때 : `cd guidebook_v4/broadcast && bash finalize.sh` (대본·화면 글자는 `content.json`, 화면 배치는 `bcast.js`, 공통 틀은 `head.js`, 빌드는 `build.js`).

## 이 책에서 "가정"으로 둔 것

- 화면 캡처는 **개발 목업(`prototype/index_260929_v2.html`)** 을 찍은 것이라 고객 이름·숫자는 모두 **예시 데이터**입니다.
- 용어 설명·모드 변경처럼 개발 중인 기능에는 **"개발 진행 중 · 오픈 시 세부 변경 가능"** 표시를 붙였습니다.
- 오늘의 추천 고객은 게시판 공지대로 **CRM 데이터 반입이 끝나는 2차 오픈부터** 보이는 것으로 썼습니다.
- 통계 숫자의 출처는 데이터분석팀 「MeAI 사용 실태 분석」·「MeAI 효과 분석」(2026.08), 7%·2% 미만은 세일즈혁신TF CRM 대문 고도화 제안(2026.09)이며 각 장에 적었습니다.
- 영업포탈 진입점 그림은 소유자가 준 기획 화면(10/2 반영분)이고, 요약 리포트·모바일 장의 휴대폰 캡처는 v3(2026.06) 실제 화면입니다. 카카오톡 캡처의 이름은 가렸습니다.

## 다시 만들려면

```
cd guidebook_v4/build
npm install                     # 처음 한 번 (pptxgenjs, sharp, playwright)
node deck.js MeAI_guidebook_v4_CRM_2026.10.pptx   # 편집용 pptx
ONLY=p4 node deck.js p4.pptx     # 한 파트만 빠르게 확인
bash finalize.sh                 # pptx + 통이미지판 + PDF 한 번에 (LibreOffice·poppler 필요)
```

문구를 고칠 때는 `build/parts/` 의 해당 파트 파일에서 한글 문장을 찾아 바꾸고 다시 만들면 됩니다.
사외로 나가는 캡처에는 개인정보(설계사명·고객명)가 없는지 확인합니다.

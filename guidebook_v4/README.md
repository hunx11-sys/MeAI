## 이 책에서 "가정"으로 둔 것

- 화면 캡처는 **개발 프로토타입(`prototype/index_260929.html`, 2026.09.29)** 을 그대로 찍은 것입니다. 고객 이름·숫자는 모두 **예시 데이터**입니다.
- 용어 설명·모드 변경처럼 아직 개발 중인 기능은 슬라이드 오른쪽 위에 **"개발 진행 중 · 오픈 시 세부 변경 가능"** 표시를 붙였습니다.
- 오늘의 추천 고객은 게시판 공지대로 **CRM 데이터 반입이 끝나는 2차 오픈부터** 보이는 것으로 썼습니다.
- 통계 숫자(91.1%, 2.8배, 4배, 2.3배, 4,912명, 65.2%, 26.9% 등)의 출처는 데이터분석팀 「MeAI 사용 실태 분석」·「MeAI 효과 분석」(2026.08), 7%·2% 미만은 세일즈혁신TF CRM 대문 고도화 제안(2026.09)입니다. 각 장에 출처를 적었습니다.
- 요약 리포트·모바일 진입 장의 휴대폰 캡처는 v3 가이드북(2026.06)의 실제 화면을 다시 썼습니다. 카카오톡 캡처의 이름은 가렸습니다.

## 다시 만들려면

```
cd guidebook_v4/build
npm install                     # 처음 한 번 (pptxgenjs, sharp, playwright)
node deck.js MeAI_guidebook_v4_CRM_2026.10.pptx   # 편집용 pptx
bash finalize.sh                 # pptx + 이미지판 + PDF 한 번에 (LibreOffice·poppler 필요)
```

문구를 고칠 때는 `build/parts/` 의 해당 파트 파일에서 한글 문장을 찾아 바꾸고 다시 만들면 됩니다.
캡처를 새로 찍을 때는 `build/cap.mjs` 를 쓰되, 사외로 나가는 캡처에는 개인정보가 없는지 확인합니다.

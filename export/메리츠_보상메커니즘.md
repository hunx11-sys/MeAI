이 문서 하나만 읽어도 `메리츠_상품보상데이터.json` 을 바로 쓸 수 있게 썼습니다.
두 파일은 한 쌍입니다. 이 문서가 **읽는 법**, JSON 이 **데이터**입니다.

## 1. 데이터 구조

### 1.1 특약 (`riders`, 951건)

```json
{
  "id": "통0",              // 상품 머리글자 + 일련번호. 고유키
  "p": "통합간편",           // 상품군 : 통합간편 307 · 케어프리 419 · 운전자 176 · 치아 49
  "n": "일반상해80%이상후유장해",  // 특약명 (약관 표기 그대로)
  "c": "disability",        // 분류 (categories 의 id)
  "pg": 123,                // 약관 쪽수
  "t": ["cd9746b4d2"],      // 연결된 별표(분류표) 키 → tables
  "k": ["C00~C14", "C73"],  // 보장 코드. 낱개 또는 범위
  "l": ["머리 및 목의 화상"],  // 코드에 대응하는 질병명 (한글 검색용)
  "s": ["화상"],             // 검색 태그 (일상 병명)
  "x": ["S02.5"],           // 제외 코드
  "st": "disability"        // 보상 단계 (stages). 드물게 배열
}
```

**빈 값이 뜻하는 것** — 이게 판정의 핵심입니다.

- `k` 가 비어 있는 특약이 **470건**입니다. 코드를 안 정한 게 아니라, 그중 **257건은 모든 질병 또는 모든 상해를 공통으로 보장**하는 특약입니다. (질병수술비, 질병입원일당, 수술비(1-7종)[상해], 일반상해사망 등)
  → 코드로 걸러내면 안 됩니다. **질병코드면 "모든 질병 공통" 120건을, 상해코드(S·T·V로 시작)면 "모든 상해 공통" 137건을 함께 보여줘야** 합니다. 이걸 빼먹으면 위암 검색에서 120건, 골절 검색에서 137건이 통째로 사라집니다. 판정 규칙은 3.5 를 그대로 쓰세요.
- `x` (제외 코드)가 있는 특약은 **117건**. 특약명에 「(유사암 제외)」처럼 드러나 있는 경우가 많습니다.
- `t` (별표 연결)가 있는 특약은 **527건**.

### 1.2 분류표 (`tables`, 216건)

약관 뒤쪽 별표입니다. `rows` 는 `{label: 질병명, codes: [코드]}` 목록입니다.

```json
"cd9746b4d2": {"name": "화상 분류표", "page": "809",
               "rows": [{"label": "머리 및 목의 화상 및 부식", "codes": ["T20"]}]}
```

### 1.3 나머지

- `codenames` : `{"C16": "위의 악성 신생물"}` — KCD 코드 → 한글 이름 1,302개
- `synonyms` : `{"위암": ["C16"], "뇌졸중": ["I60","I61","I62","I63","I65","I66"]}` — **판정에 쓰는** 병명→코드 77개
- `aliases` : `{"중풍": [...], "심장마비": ["I21"]}` — **검색에만 쓰는** 별칭 30개. 판정에 넣으면 사각지대가 중복으로 뜹니다
- `products` : 상품 50종. 가입나이·만기·납입면제·알릴의무 유형·플랜·특징
- `stages` : 보상 단계 10개 (진단→검사→수술→입원→통원→치료→간병·요양→후유장해→사망→기타)
- `categories` : 특약 분류 22개

## 2. 코드 표기 규칙 — 가장 자주 틀리는 곳

### 2.1 범위 기호가 세 가지입니다

약관 원문은 범위를 **세 가지 기호로 섞어** 씁니다. 실제로 세어 본 값입니다.

| 기호 | 유니코드 | 횟수 | 예 |
|---|---|---|---|
| `~` | U+007E | 311 | `C00~C14` |
| `∼` | U+223C | 45 | `I20∼I25` |
| `-` | U+002D | 41 | `N17-N19` |

**`~` 만 처리하면 45+41곳이 조용히 깨집니다.** 범위가 양 끝 코드 2개로 쪼개지면서 사이가 전부 사라집니다.

> 실제 사고 사례 — 다른 팀 규칙 파일에서 `I20∼I25` 가 `"I20, I25"` 로 저장되어 **급성심근경색(I21·I22·I23)이 빠졌고**, `K35∼K38` 이 `"K35, K38"` 이 되어 **상세불명 충수염(K37)** 이 빠졌습니다. 한 파일에서 코드 59개가 누락됐습니다.

파싱할 때 세 기호를 모두 같게 다루세요. `[~∼〜～\-–—]`

### 2.2 세부코드(소수점)

`S02.5`, `D47.1`, `C79.80` 처럼 소수점이 붙습니다. 판정에서 이 둘을 구별해야 합니다.

- **카테고리 전체 제외** (`"C44"`) → 그 코드는 보장 대상에서 통째로 빠짐
- **세부코드만 제외** (`"S02.5"`) → 카테고리(S02)는 살아 있고 **일부만** 빠짐 → 화면에는 "일부 보장"으로 표시

### 2.3 KCD 에 없는 번호

`C35 · C36 · C87 · C89 · D08` 은 **한국표준질병사인분류에 그 번호 자체가 없습니다.** 범위를 펼쳤을 때 이들이 빠져 있어도 오류가 아닙니다. 빠졌다고 보고하면 오탐입니다.

## 3. 보장 판정

### 3.1 코드 하나가 특약에 들어 있는가

```
listHasCode(k, code, x):
    code 를 대문자로
    x(제외코드)에 code 가 있으면 → 미보장
    k 의 토큰 중 하나라도 code 를 품으면 → 보장

rangeHas(토큰, code):
    토큰이 "C00~C14" 꼴이면 앞글자·숫자 범위로 판단 (글자가 다른 범위도 지원)
    아니면 소수점을 떼고 정확히 같은지 비교
```

### 3.2 실보장 집합 (effSet)

```
effSet(특약) = 보장코드를 3자리로 펼친 집합 − 카테고리 전체 제외 코드
```
세부코드 제외(`S02.5`)는 **카테고리를 지우지 않습니다.**

### 3.3 보장 등급 (covType)

| 값 | 뜻 | 조건 |
|---|---|---|
| `y` | 보장 | effSet 에 있고, 그 카테고리의 세부코드 제외가 없음 |
| `p` | 일부 보장 | effSet 에 있으나 세부코드 제외(`S02.5` 등)가 걸려 있음 |
| `n` | 미보장 | effSet 에 없음 |

### 3.5 공통 특약 판정 (그대로 옮겨 쓰세요)

`k` 와 `s` 가 **둘 다** 비어 있는 특약만 대상입니다. 특약명으로 질병용인지 상해용인지 가립니다.

```
공통특약_종류(특약):
    k 나 s 가 하나라도 있으면 → 공통 아님 (null)

    n = 특약명에서 공백 제거
    n 에서 "(치아파절및치아탈구제외)" 제거
    n 에서 "(특정N대질병제외)" 제거                 ← 이 괄호 때문에 '질병'으로 오인됨

    n 에 아래 낱말이 있으면 → 공통 아님 (null)
        치아 치과 치조골 보철 임플란트 크라운
        배상책임 벌금 변호사 법률 화재 가전 재물
        운전 자동차 교통 면허 생활지원 산정특례

    질병 = ("질병" 포함) 그리고 (특정·대질병·요양성·다빈도·성인병·여성·남성 없음)
    상해 = ("상해" 포함) 그리고 (특정·골절·화상·깁스·성형·중대한 없음)

    질병만 참 → "모든 질병 공통"
    상해만 참 → "모든 상해 공통"
    둘 다거나 둘 다 아니면 → 공통 아님
```

검색한 코드가 **S·T·V로 시작하면 상해**, 아니면 질병으로 보고 해당 쪽 공통 특약을 붙입니다.

> 이 규칙을 그대로 돌리면 **질병 공통 120건 · 상해 공통 137건**이 나옵니다. 숫자가 다르면 구현이 틀린 것입니다.

### 3.4 유사암 판정

유사암(소액암)은 **일반암보다 적게 지급**하므로 반드시 구분해야 합니다.

```
유사암 = C44(기타피부암) · C73(갑상선암) · D00~D09(제자리암) · D37~D48(경계성종양)
```

판정할 때는 소수점을 떼고 3자리로 봅니다. 그래서 `D47.1` 도 이 함수로는 유사암(D47)으로 나옵니다.

> **함정** — `D47.1 · D47.3 · D47.4 · D47.5` 는 D47 대역이지만 **약관상 일반암**입니다.
> (만성골수증식질환 · 본태성혈소판혈증 · 골수섬유증 등)
> 이 함수만으로 "D47 = 유사암" 이라고 단정하면 안 되고, **4장 사각지대 예외 2번**에서 바로잡습니다.
> 암(유사암제외) 특약은 D47 전체가 아니라 이 세부코드들만 갖고 있기 때문입니다.

## 4. 사각지대 분석 (blindSpots)

일상 병명 하나가 코드 여러 개를 묶는데, 특약이 **그중 일부만** 보장하는 경우를 찾습니다.

```
동의어(synonyms) 의 각 병명에 대해:
    코드가 2개 미만이면 건너뜀
    보장되는 코드(cov) 와 안 되는 코드(miss) 로 나눔
    둘 다 있으면 → 사각지대
빠진 코드가 적은 순, 보장 코드가 많은 순으로 정렬해 상위 4건
```

**반드시 넣어야 하는 예외 두 가지.** 없으면 잘못된 경고가 쏟아집니다.

1. **일반암과 유사암이 섞인 병명은 제외.**
   예) 피부암 = C43(악성흑색종, 일반암) + C44(기타피부암, 유사암).
   어떤 특약이든 구조적으로 반쪽만 보장하므로 경고 가치가 없습니다.

2. **유사암만으로 된 병명은 분류를 통째로 보장할 때만 "보장"으로 센다.**
   암(유사암제외) 특약은 D47.1·D47.3 같은 세부코드만 갖고 있는데, 이걸 "D47 보장"으로 세면 **"경계성종양 중 1/10만 보장"** 이라는 엉터리 사각지대가 뜹니다. 실제로 특약 125건에서 이 오류가 났습니다.

3. **약관이 제외코드로 명시한 것은 사각지대가 아닙니다.** 「암진단비(유사암제외)」의 C44 처럼 특약명에 이미 드러나 있으면 분모에서도 뺍니다.

## 5. 상위호환 분석 (superiors)

같은 상품·같은 급부에서 내 보장을 전부 포함하면서 더 넓은 특약을 찾습니다.
**단순히 코드 수만 비교하면 엉뚱한 특약이 나옵니다.** 특약명에서 세 종류의 낱말을 읽어야 합니다.

| 종류 | 뜻 | 예 |
|---|---|---|
| **확장어** | 이 말이 붙으면 보장이 넓어짐 | 전이포함 · 통합 · 재진단 · 원격전이 · 무제한 · 체증 · 두배 |
| **제한어** | 지급 장소·횟수가 좁아짐 | 상급종합병원 · 종합병원 · 요양병원 · 최초1회한 · 연간1회한 |
| **지급사유어** | **치료 수단이 다르면 애초에 다른 담보** | 호르몬 · 항암 · 방사선 · 표적 · 면역 · 로봇 · 관혈 · MRI · 비급여 · 간병인 |

```
상위호환 조건 :
    같은 상품 · 같은 급부(진단/수술/입원/통원/간병/치료)
    내 확장어를 전부 갖추고 있을 것
    내게 없는 제한어가 붙어 있지 않을 것
    지급사유어 집합이 정확히 같을 것      ← 이게 없으면 오탐이 많음
    실보장 집합이 내 것을 전부 포함하고 더 클 것
```

> 「매월 계속암치료비」와 「특정호르몬약물허가치료비」는 둘 다 암 치료비지만 **지급사유가 달라** 상위호환이 아닙니다.

**급부 구분** — 특약명에서 이 순서로 찾습니다:
통원 → 간병 → 입원/일당 → 수술/시술 → 진단 → 치료 → 기타

## 6. 보상 시뮬레이터 — 단계별 보장

질병코드나 병명을 넣으면 **치료 흐름 순서대로** 어떤 특약이 걸리는지 보여줍니다.

```
진단 시 → 검사 시 → 수술 시 → 입원 시 → 통원 시 → 치료 시
       → 간병·요양 시 → 후유장해 시 → 사망 시 → 기타 보장
```

특약별 단계는 `st` 필드입니다. 분포는 치료 237 · 진단 180 · 수술 164 · 간병 124 · 기타 98 · 입원 60 · 후유장해 37 · 통원 22 · 검사 21 · 사망 16 입니다.

**공통 특약(`k` 없음 470건)은 각 단계의 뒤쪽에 "모든 질병 공통 / 모든 상해 공통" 배지와 함께 붙입니다.** 앞에 섞으면 정확히 일치하는 특약이 묻힙니다.

## 7. 검색

1. **특약명** — 띄어쓰기 무시 비교. 단, 검색어가 「(○○ 제외)」 괄호 **안에만** 있으면 제외 (실제로 보장 안 하므로)
2. **초성 검색** — `ㅇㄱ` → 위암
3. **질병명 태그**(`s`)·**질병명 라벨**(`l`)
4. **코드** — `C73` 정확, `C7` 접두 모두 지원
5. **병명 → 코드** — `synonyms` + `aliases` 로 코드를 얻어 `listHasCode` 로 판정

> `aliases` 는 **검색에만** 쓰세요. 사각지대·상위호환 판정에 넣으면 같은 경고가 두 번 뜹니다.

## 8-1. 통합치료비 — 같은 이름의 검사라도 특약마다 범위가 다릅니다

통합치료비 특약은 검사·치료 항목마다 **약관이 수가코드를 낱낱이 적어 둡니다.**
이름이 비슷해도 특약이 다르면 대상이 다릅니다. 여기서 과다 안내가 가장 많이 납니다.

| 항목 | 암 통합치료비 | 암전후관련 특정질환 및 양성신생물 통합치료비 |
|---|---|---|
| 내시경 | 「암 내시경검사(급여)」 = 급여 **제2부 제2장 검사료 제4절 내시경 전체** | 「특정내시경(급여)」 = **수가코드 13개만 열거** (약관 제9조) |
| 위·대장내시경 | **포함** | **불포함** — 흉강경·종격동·담췌관·소장·후복강경·요관경·신내시경뿐 |
| 생검 | 「암 특정생검조직병리검사(급여)」 = **수가코드 31개 열거** | 「특정생검(급여)」 = **26개 열거** + 「수술 중 절제생검(excisional biopsy)」 **명시 제외** (약관 제8조) |
| 내시경 겸자생검 | **불포함** (목록이 전부 침생검·절개생검·장기별 생검) | **불포함** |

**생검 목록에 이름이 있는 것** — 침생검(복막·흉막·장기·심낭·척수) · 골수천자생검 ·
절개생검(개흉·개복) · 전립선 · 고환/부고환 · 자궁내막 · 자궁경부착공 · 골 · 갑상선 ·
관절절개 · 신경 · 경정맥간 · 심근 · 유방(침생검·절개생검).

**없는 것** — 내시경 겸자생검(위·대장·방광·기관지) · 림프절 생검 · 피부 생검 ·
내시경초음파 유도 세침흡인(EUS-FNA) · 맘모톰(진공보조흡인절제).

> 판정 원칙 : **약관이 코드를 열거한 항목은, 목록에 이름이 있을 때만 지급으로 본다.**
> 같은 「조직검사」라도 유방 침생검은 지급이고 위내시경 겸자생검은 아닙니다.

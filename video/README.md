# 영상 만들기 (오픈몽타주)

「영상 만들어줘」라고 말하면 기획부터 완성 mp4 까지 만들어 주는 도구를 붙여 둔 곳입니다.
쓰는 프로그램은 **오픈몽타주(OpenMontage)** 라는 무료 공개 프로그램입니다(공식 저장소 github.com/calesthio/OpenMontage).

## 어떻게 쓰나

이 저장소에서 클로드에게 말로 요청하면 됩니다. 클로드가 알아서 설치하고(1분 안쪽) 진행합니다.

- 「MeAI 영업지원도구 소개 영상 45초짜리 만들어줘」
- 「플라이휠 PPT 를 60초 세로 쇼츠로 만들어줘」
- 「특약검색기 쓰는 법을 화면 시연 영상으로 만들어줘」
- 「이 영상처럼 만들어줘 (참고 영상 파일 첨부)」

진행 순서는 **기획안 제안 → 대본 확인 → 장면 구성 확인 → 제작 → 점검 → 전달** 입니다.
단계마다 확인을 받고 넘어가므로, 마음에 안 드는 부분은 그때 말씀하시면 됩니다.

완성본은 `video/out/` 폴더에 놓이고 채팅으로도 보내 드립니다.
작업 컴퓨터가 임시라서 세션이 끝나면 지워집니다. **받은 파일은 내려받아 두세요.**

## 지금 되는 것

| 되는 것 | 설명 | 확인 |
|---|---|---|
| 글자 · 도형 · 표 · 그래프가 움직이는 영상(모션그래픽) | 설명 영상, 숫자 강조, 비교 화면, 제목 화면 등 | 직접 만들어 확인 |
| 한글 화면 | 프리텐다드 글꼴로 나옵니다 | 직접 만들어 확인 |
| 배경음 | 기본 3곡(잔잔한 곡 · 밝은 곡 · 집중용 곡)이 들어 있습니다. 직접 합성한 단순한 곡입니다 | 직접 만들어 확인 |
| 자막 넣기, 자르기 · 붙이기, 색 보정 | 가지고 계신 영상 · 그림 파일로 편집 | 도구 설치됨 · 아직 안 돌려 봄 |
| 화면 시연 영상 | 도구 화면을 찍어 설명을 얹는 영상 | 도구 설치됨 · 아직 안 돌려 봄 |
| 세로(쇼츠) · 정사각 | 요청할 때 말씀하시면 됩니다 | 아직 안 돌려 봄(가로 1920×1080 만 확인) |

더 좋은 음악을 쓰고 싶으면 저작권 문제 없는 mp3 를 `video/music/` 폴더에 올려 두세요. 그 곡이 먼저 쓰입니다.

## 막혀 있는 것 (2026-11-21 기준)

이 작업 환경은 보안을 위해 허용된 인터넷 주소만 드나들 수 있습니다. 그래서 아래 세 가지는 아직 안 됩니다.

| 안 되는 것 | 이유 |
|---|---|
| **내레이션(읽어 주는 목소리)** | 무료 음성 프로그램은 설치됐지만, 목소리 파일을 받는 주소(huggingface.co)가 막혀 있습니다. 또 그 무료 프로그램에는 한국어 목소리가 공식으로는 없습니다 |
| **인터넷 무료 실사 영상 · 무료 음악** | NASA · 위키미디어 · Pixabay 등의 주소가 막혀 있습니다 |
| **AI 가 그려 주는 그림 · 영상, 말하는 아바타** | 유료 서비스의 키가 필요합니다(선택 사항) |

### 막혀 있는 것을 풀려면

필요해질 때 클로드에게 「내레이션도 넣고 싶어」처럼 말씀하시면 그때 안내해 드립니다. 방법은 셋 중 하나입니다.

1. **주소 허용** : 환경 설정의 허용 목록에 주소를 추가합니다(승인 창에서 한 번 누르면 됩니다). 무료 실사 영상 · 무료 음악은 이 방법입니다.
2. **음성 서비스 키 등록** : 한국어 내레이션은 이쪽이 품질이 좋습니다(구글 · 일레븐랩스 · 오픈AI 등). 키는 채팅에 붙여 넣지 않고 보안 입력 창에 넣습니다. 키를 저장하면 그 서비스 주소도 함께 열립니다. 서비스에 따라 요금이 듭니다.
3. **직접 녹음** : 녹음한 음성 파일을 올려 주시면 영상에 얹고 자막을 맞춥니다. 추가 설정이 필요 없습니다.

## 속도 (2026-11-21 측정 · 4코어 작업 컴퓨터)

- 설치 : 빈 상태에서 41초
- 둘째 엔진(HyperFrames) : 4초 영상 6초
- 첫째 엔진(Remotion) : 20초 영상 약 100초(1초에 5장쯤)

## 라이선스 · 주의

- 오픈몽타주 : AGPL-3.0. 받아서 쓰는 것은 자유이고, 그 코드는 이 저장소에 넣지 않습니다.
- 화면 엔진 HyperFrames : Apache-2.0(회사 업무용에 제한 없음). **회사에서 쓸 영상은 이 엔진을 권합니다.**
- 화면 엔진 Remotion : 패키지 설명에 「경우에 따라 회사 라이선스를 사야 한다」고 적혀 있습니다. 회사 업무용으로 쓰기 전에 remotion.dev/license 의 조건을 확인해야 합니다(이 환경에서는 원문을 열어 보지 못했습니다).
- 글꼴 프리텐다드 : SIL OFL 1.1.
- 영상에도 저장소 규칙이 그대로 적용됩니다 : 숫자는 출처 또는 「가정값」 표기, 설계사명 · 고객 정보는 화면에 넣지 않음, 파일명은 영문.

## 이 폴더에 있는 것

| 파일 | 하는 일 |
|---|---|
| `openmontage_setup.sh` | 설치 · 점검. 몇 번 돌려도 안전. `--smoke` 를 붙이면 한국어 시험 영상까지 만듭니다 |
| `env.sh` | 영상 명령을 칠 때 불러오는 환경값(빠른 브라우저 지정 · 사용 통계 끄기 · 폴더 위치) |
| `remotion.config.ts` | 화면을 찍는 브라우저를 새로 내려받지 않고 이미 있는 것을 쓰게 하는 설정 |
| `make_music.py` | 기본 배경음 3곡을 직접 합성 |
| `smoke_ko.json` | 한국어 시험 영상의 내용 |
| `music/` | (선택) 쓰고 싶은 음악 파일을 넣는 곳 |
| `out/` | 완성본이 놓이는 곳(저장소에는 올리지 않음) |

클로드가 따르는 작업 순서는 `.claude/skills/openmontage/SKILL.md` 에 있습니다.

## 변경 기록

### 2026-11-21 처음 설치

- 소개 글(visionstory.ai 의 「OpenMontage 완전 해설」)과 공식 저장소의 README · AGENT_GUIDE 를 읽고 설치했습니다. 받은 판은 2026-11-15 판(커밋 `2e003e6`)으로 고정했습니다.
- 그대로는 영상이 안 뽑혔습니다. 화면을 찍는 브라우저를 내려받는 주소(remotion.media)가 막혀 있었기 때문입니다 → 작업 컴퓨터에 이미 있는 브라우저를 쓰도록 설정을 얹어 해결했습니다.
- 한글 글꼴이 없어 한글이 대체 글꼴로 나올 상황이었습니다 → 프리텐다드를 설치하고 기본 글꼴로 지정했습니다.
- 둘째 엔진이 느린 방식으로 돌고 있었습니다(4초 영상 85초) → 캡처 전용 브라우저를 지정해 6초로 줄였습니다.
- 둘째 엔진의 사용 통계 전송을 껐습니다.
- 무료 음악을 받는 주소가 막혀 있어, 배경음 3곡을 직접 합성해 넣었습니다.
- 확인한 것 : 빈 폴더에서 스크립트 하나로 설치(41초 · 정상 종료), 첫째 엔진 견본 영상(23초 · 1920×1080), 한국어 시험 영상(20초 · 배경음 포함 · 한글 정상), 둘째 엔진 한글 영상(4초).
- 확인하지 못한 것 : 내레이션, 인터넷 무료 재료 받기, AI 생성(위 「막혀 있는 것」). 오픈몽타주의 전체 제작 과정(기획 → 승인 → 제작)을 실제 주제로 끝까지 돌려 본 것은 아직 없습니다.
- 주소 7개(음성 모델 · 무료 음악 · 무료 영상 자료) 허용 요청은 소유자가 거절했습니다. 허용된 것은 소개 글 주소(www.visionstory.ai) 하나입니다.

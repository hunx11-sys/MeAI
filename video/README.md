# 영상 만들기 (오픈몽타주)

「영상 만들어줘」라고 말하면 기획부터 완성 mp4 까지 만들어 주는 도구를 붙여 둔 곳입니다.
쓰는 프로그램은 **오픈몽타주(OpenMontage)** 라는 무료 공개 프로그램입니다(공식 저장소 github.com/calesthio/OpenMontage).

## 어떻게 쓰나

이 저장소에서 클로드에게 말로 요청하면 됩니다. 클로드가 알아서 설치하고(1분 안쪽) 진행합니다.

- 「MeAI 영업지원도구 소개 영상 45초짜리 만들어줘」
- 「플라이휠 PPT 를 60초 세로 쇼츠로 만들어줘」
- 「특약검색기 쓰는 법을 화면 시연 영상으로 만들어줘」
- 「이 영상처럼 만들어줘 (참고 영상 파일 첨부)」

진행 순서는 **기획안 제안 → 대본 확인 → 장면 구성 확인 → 제작 → 점검 → 전달** 입니다.
단계마다 확인을 받고 넘어가므로, 마음에 안 드는 부분은 그때 말씀하시면 됩니다.

완성본은 `video/out/` 폴더에 놓이고 채팅으로도 보내 드립니다.
작업 컴퓨터가 임시라서 세션이 끝나면 지워집니다. **받은 파일은 내려받아 두세요.**

| 되는 것 | 설명 | 확인 |
|---|---|---|
| 글자 · 도형 · 표 · 그래프가 움직이는 영상(모션그래픽) | 설명 영상, 숫자 강조, 비교 화면, 제목 화면 등 | 직접 만들어 확인 |
| 한글 화면 | 프리텐다드 글꼴로 나옵니다 | 직접 만들어 확인 |
| 배경음 | 기본 3곡(잔잔한 곡 · 밝은 곡 · 집중용 곡)이 들어 있습니다. 직접 합성한 단순한 곡입니다 | 직접 만들어 확인 |
| **한국어 내레이션(읽어 주는 목소리)** | 무료 · 키 없음 · 이 컴퓨터 안에서 합성. 목소리 10종(0~4번 여성, 5~9번 남성 — 음높이로 추정). 문장 단위 자막 시간도 같이 나옵니다 | 파일은 만들어 확인 · **발음은 소유자가 들어 봐야 함**(클로드는 소리를 듣지 못합니다) |
| 자막 넣기, 자르기 · 붙이기, 색 보정 | 가지고 계신 영상 · 그림 파일로 편집 | 도구 설치됨 · 아직 안 돌려 봄 |
| 화면 시연 영상 | 도구 화면을 찍어 설명을 얹는 영상 | 도구 설치됨 · 아직 안 돌려 봄 |
| 세로(쇼츠) · 정사각 | 요청할 때 말씀하시면 됩니다 | 아직 안 돌려 봄(가로 1920×1080 만 확인) |

더 좋은 음악을 쓰고 싶으면 저작권 문제 없는 mp3 를 `video/music/` 폴더에 올려 두세요. 그 곡이 먼저 쓰입니다.

## 한국어 내레이션 (2026-11-22 연결)

- 쓰는 것 : **Supertonic 3**(한국 회사 수퍼톤이 공개한 음성 합성 모델 · 한국어 포함 31개 언어) + **sherpa-onnx**(공개 음성 엔진).
- 요금 · 키 · 가입 없음. 글이 바깥 서비스로 나가지 않고 작업 컴퓨터 안에서 소리로 바뀝니다.
- 속도 : 11초 분량을 약 2.5초에 만듭니다.
- 요청할 때 「3번 목소리로」 「조금 빠르게」처럼 말씀하시면 됩니다. 목소리 견본은 `video/out/korean_voice_samples.mp3`(채팅으로도 보냄).
- **들어 보고 알려 주실 것** : 숫자(2026년, 35,000원) · 영어 낱말 · 상품명 발음이 자연스러운지. 어색하면 대본에서 그 부분을 한글로 풀어 씁니다(예 「35,000원」 → 「삼만 오천 원」).
- 한계 : 감정 연기나 특정인 목소리 흉내는 안 됩니다. 화면 자막의 낱말별 강조 시간은 문장 길이를 글자 수로 나눈 어림값입니다(문장 시작 · 끝 시간은 정확).
- 목소리 파일을 받는 길 : 원래 보관소(huggingface.co)는 이 환경에서 막혀 있어, 같은 모델을 노드 패키지 저장소(npm)에 올려 둔 재포장본(`@3sln/donki-lle-voice-multi` 세 묶음 0.1.1)에서 받습니다. 패키지 안의 프로그램은 실행하지 않고 데이터만 꺼내며, 처음 받았을 때의 지문값(SHA256)과 같을 때만 씁니다. 수퍼톤이 직접 올린 것이 아니라 제3자가 다시 포장한 것이라는 점은 알아 두세요.
- 수퍼톤이 2026년 여름에 사업을 정리했다는 글이 검색에 나옵니다(공식 확인은 못 했습니다). 사실이면 모델이 더 좋아지지는 않지만, 지금 받은 것은 그대로 쓸 수 있습니다.

## 막혀 있는 것 (2026-11-22 기준)

이 작업 환경은 보안을 위해 허용된 인터넷 주소만 드나들 수 있습니다. 그래서 아래 두 가지는 아직 안 됩니다.

| 안 되는 것 | 이유 |
|---|---|
| **인터넷 무료 실사 영상 · 무료 음악** | NASA · 위키미디어 · Pixabay 등의 주소가 막혀 있습니다 |
| **AI 가 그려 주는 그림 · 영상, 말하는 아바타** | 유료 서비스의 키가 필요합니다(선택 사항) |

### 막혀 있는 것을 풀려면

필요해질 때 클로드에게 말씀하시면 그때 안내해 드립니다.

1. **주소 허용** : 환경 설정의 허용 목록에 주소를 추가합니다(승인 창에서 「허용」을 누르면 됩니다). 무료 실사 영상 · 무료 음악은 이 방법입니다.
2. **서비스 키 등록** : AI 그림 · 영상, 더 자연스러운 유료 목소리(구글 · 일레븐랩스 등). 키는 채팅에 붙여 넣지 않고 보안 입력 창에 넣습니다. 서비스에 따라 요금이 듭니다.
3. **직접 가진 재료 올리기** : 찍어 둔 영상 · 사진 · 녹음 파일을 올려 주시면 그것으로 편집합니다. 추가 설정이 필요 없습니다.

## 속도 (2026-11-21 측정 · 4코어 작업 컴퓨터)

- 둘째 엔진(HyperFrames) : 4초 영상 6초

## 라이선스 · 주의

- 오픈몽타주 : AGPL-3.0. 받아서 쓰는 것은 자유이고, 그 코드는 이 저장소에 넣지 않습니다.
- 화면 엔진 HyperFrames : Apache-2.0(회사 업무용에 제한 없음). **회사에서 쓸 영상은 이 엔진을 권합니다.**
- 화면 엔진 Remotion : 패키지 설명에 「경우에 따라 회사 라이선스를 사야 한다」고 적혀 있습니다. 회사 업무용으로 쓰기 전에 remotion.dev/license 의 조건을 확인해야 합니다(이 환경에서는 원문을 열어 보지 못했습니다).
- 글꼴 프리텐다드 : SIL OFL 1.1.
- 목소리 모델 Supertonic 3 : OpenRAIL-M(쓰는 것은 자유이되 남을 속이거나 해치는 용도 등은 금지하는 조건부 라이선스). 정식 조건은 모델 보관소의 LICENSE 에 있습니다(이 환경에서는 원문을 열어 보지 못했습니다). 음성 엔진 sherpa-onnx : Apache-2.0.
- **실제 사람인 것처럼 들리는 목소리**이므로, 고객에게 나가는 영상에는 「AI 음성」임을 밝히는 것을 권합니다.
- 영상에도 저장소 규칙이 그대로 적용됩니다 : 숫자는 출처 또는 「가정값」 표기, 설계사명 · 고객 정보는 화면에 넣지 않음, 파일명은 영문.

## 이 폴더에 있는 것

| 파일 | 하는 일 |
|---|---|
| `openmontage_setup.sh` | 설치 · 점검. 몇 번 돌려도 안전. `--smoke` 를 붙이면 한국어 시험 영상까지 만듭니다 |
| `env.sh` | 영상 명령을 칠 때 불러오는 환경값(빠른 브라우저 지정 · 사용 통계 끄기 · 폴더 위치) |
| `remotion.config.ts` | 화면을 찍는 브라우저를 새로 내려받지 않고 이미 있는 것을 쓰게 하는 설정 |
| `make_music.py` | 기본 배경음 3곡을 직접 합성 |
| `korean_voice.py` | 한국어 내레이션 : 목소리 모델 받기 · 검증, 글 → 소리 파일 · 자막 시간 |
| `overlay/supertonic_tts.py` | 위 내레이션을 오픈몽타주의 음성 도구로 등록하는 연결 파일(설치 때 오픈몽타주 쪽에 복사) |
| `smoke_build.py` | 시험 영상의 내레이션 · 장면 시간 · 자막을 만드는 스크립트 |

| `music/` | (선택) 쓰고 싶은 음악 파일을 넣는 곳 |
| `out/` | 완성본이 놓이는 곳(저장소에는 올리지 않음) |

## 변경 기록

### 2026-11-22 한국어 내레이션 연결

- 소유자 요청 : 「내레이션이 한글로 되게 해 주는 무료 프로그램을 찾아 연결」.
- 찾은 것 : Supertonic 3(한국어 지원 · 일반 컴퓨터에서 빠름) + sherpa-onnx. 살펴본 다른 후보(직접 돌려 보지는 않음) — Piper(공식 목소리 목록에 한국어가 없는 것으로 알고 있음), Kokoro · MeloTTS · Chatterbox(모델을 주로 huggingface 에서 받는 방식이라 이 환경에서는 같은 문제에 걸림), 엣지 TTS(마이크로소프트 온라인 서비스를 비공식으로 쓰는 방식이고 새 주소도 열어야 해서 제외).
- 목소리 파일 : huggingface.co 허용 요청(주소 2개)을 소유자가 거절 → 이미 열려 있는 npm 에서 재포장본을 받아 지문값 검증 후 사용.
- 오픈몽타주에 음성 도구 `supertonic_tts`(provider `supertonic`)로 등록. 음성 선택기의 자동 선택도 이 목소리를 고릅니다(목소리 파일이 없는 Piper 는 잘못 뽑히지 않게 꺼 둠).
- 확인한 것 : 스크립트만으로 모델 받기 · 검증(전체 30초), 음성 선택기 경유 합성(12.8초 분량 4.9초), 문장 단위 자막(SRT), 내레이션 + 낱말 자막 + 배경음이 들어간 시험 영상 36초(1920×1080).
- 확인하지 못한 것 : **발음 품질**(클로드는 소리를 듣지 못함 — 숫자 · 영어 · 상품명 읽기는 소유자가 들어 봐야 함). 소리 크기와 길이, 문장별 구간이 정상이라는 것까지만 확인했습니다.
